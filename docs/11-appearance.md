# 村人の見た目(顔・髪・頭の形)

それまでの村人は、全員、同じ丸い頭と四角い鼻だった。**目・鼻・口・髪型・頭の形を、それぞれ何パターンも用意し、人ごとに組み合わせが重ならないようにした。**

- 見た目のデータ: `game/src/appearance.ts`(描画に依存しない。Node でも動く)
- 描画: `game/src/faces.ts`(インスタンシング)
- 確認: `npm run appearance-check`(組み合わせの重なり)、`?lineup=1` / `?lineup=2`(目の前に6人を並べて、顔を見比べる。時間は止まる)

## パターン

| 部品 | パターン |
| --- | --- |
| 頭の形 | 6種(丸い・縦長・横広・小さめ・大きめ・たまご型。幅・高さ・奥行きが違う) |
| 髪型 | 10種(坊主頭の無し・短く刈る・短髪・ロング・ボブ・ポニーテール・ツンツン・アフロ・お団子・モヒカン)。頭の形に合わせて、髪も伸び縮みする |
| 髪の色 | 9種。黒・こげ茶・茶が多く、金・赤・白髪まじり・白・青(染めた)は、まれ(現実に近い出やすさ) |
| 肌の色 | 6種(明るい〜濃い。出やすさは、偏りあり) |
| 目 | 形3種(丸い・細い・縦長)× 大きさ4段 × 間隔3段 × 高さ3段 × 色5種(黒・茶・青・緑・灰)。白目と黒目の2層で描く |
| 眉 | 角度5段(下がり眉〜つり眉)× 太さ3段。色は髪の色 |
| 鼻 | 幅3 × 長さ3 × 出っぱり3 |
| 口 | 3種(一文字・にっこり・開いた口)× 大きさ3 × 位置3 |
| 眼鏡 | 約18% |
| ひげ | 口ひげ約10%、あごひげ約8% |

## 同じ顔にならないしくみ

- 全パターンの組み合わせは、数百万通りあり、村人の人数分の見た目を、**重なったら引き直す**ことで、全員違うようにしている。
- 同じ seed なら、毎回、同じ人が、同じ顔になる(セーブ・再現のため)。
- 乱数は、見た目専用の流れを使う。**性格・経済など、ほかの乱数の流れは変えていない**(検証済みの調整が、ずれないように)。

測定(`appearance-check`):

| 人数 | 見た目の組み合わせ | 顔(目・眉・鼻・口)だけでも |
| --- | --- | --- |
| 51人 | 51通り(重なり 0) | 51通り |
| 300人 | 300通り(重なり 0) | 300通り |
| 1000人 | 1000通り(重なり 0) | 1000通り |

300人の内訳: 髪型は 10種が 15〜45人ずつ、口は 3種が約100人ずつ、眼鏡 46人、ひげ 56人。

## 描画の工夫(負荷)

- 髪型ごと、口の種類ごとに、別々のインスタンシング(1つの部品が1回の描画)にして、村人ごとに「スロット」を割り当てる。描画の呼び出しは、顔まわりで約20回ほど(髪型10種 + 目・眉・鼻・口・眼鏡・ひげ)。
- 毎フレームは、村人の頭の位置に、**最初に決めた部品の位置・大きさを掛ける**だけ。建物の中にいる村人は、大きさ 0 で消す(これまでと同じ)。
- 髪の形は、球の帽子型を後ろへ傾けて、前髪の生え際が高く・後ろが低くなるようにし、ロングやボブは、箱や筒を足して作る。部品を1つの形に合成してあるので、人数が増えても、髪型の数ぶんしか描画は増えない。

## 試行錯誤

- 最初は、鼻が大きな四角で、目の上に重なって見えた。**小さな丸い鼻**に変え、位置を下げた。
- 眉は、外側が上がるほど、きつい目つきに見える。角度の向きを確かめて、左右対称になるように、左右で逆にした。
- 髪の帽子型が、そのままでは、目まで隠した。後ろへ傾けて、前髪の生え際を目の上に保つようにした。

## 残っている課題

- 見た目は、顔まわりだけ。**体つき(背の高さ・太さ)・服の形**は、まだ全員同じ(服の色だけ違う)。
- プレイヤーの体(見下ろし視点で見える赤い服の人)は、この顔のしくみを使っていない。顔が見えるのは、鏡や写真がないため、まだ、他の人から見える場面だけ。
- 表情(怒る・笑う)で顔が変わることはない。
- 実際のモニタや、遠くから見たときの見え方は、未確認。近くで静止画を確かめた。
