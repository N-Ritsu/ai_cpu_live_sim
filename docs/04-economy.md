# コンビニ・食料品・お金

「1つずつ整理する」の2番目。コンビニで食料品を買えるようにし、働くとお金が増えるようにした。あわせて、時間を止めるポーズ機能を付けた。(その後、1日を5分にした。下の「あとから変えたこと」。)

## 何ができるか

- **コンビニ**(広場の東)。24時間やっていて、食料品を売っている。村人は、お腹が空くとここへ買いに行き、買ったものを食べる。
- **食料品は5種類**。
- **お金**: 村人は畑仕事を終えると賃金をもらう。食料品を買うとお金が減る。
- **持ち物**: 村人は食料品を最大3個まで持ち歩ける。持っていれば、買わずにその場で食べる。
- **プレイヤー**: コンビニの入口の近くで F を押すと、商品一覧が開く(数字キーで買う)。畑の中で F を押し続けると、働いてお金が入る。所持金は ¥1,000 から。
- **ポーズ**: Space か P で、時間(村人・昼夜)を止める。止めている間も、視点を回す・村人をクリックして中身を見る、はできる。

## 食料品

| 食料品 | 値段 | 満腹 | 食べる時間 | 満腹1あたり |
| --- | --- | --- | --- | --- |
| お菓子 | ¥120 | +0.2 | 5分 | ¥600 |
| おにぎり | ¥150 | +0.4 | 8分 | ¥375 |
| カップ麺 | ¥200 | +0.5 | 12分 | ¥400 |
| サンドイッチ | ¥250 | +0.55 | 10分 | ¥455 |
| お弁当 | ¥500 | +0.9 | 20分 | ¥556 |

(時間はゲーム内の時間。)安い物が得とは限らない: おにぎりがいちばん割安で、お菓子はいちばん割高。

## お金の流れ

- **賃金**: 畑仕事1回(4時間)で ¥800。(のち、職業ごとの給料に変わった。[08-jobs.md](08-jobs.md))
- **1日の食費**: 満腹は1日で 1.08 減る → 食料品に約 ¥500〜700。
- **お金が少ない人は働く**: 所持金が ¥900 未満だと、働く動機が加点される(少ないほど強い)。逆に ¥1,500 を超えると働く動機が下がる。これで、所持金が一定の水準で落ち着く。

## 村人の判断(ai_cpu に渡している行動の定義)

食料品ごとに「買う」と「食べる」の行動を作っている(`buy_onigiri`、`eat_onigiri` など)。

- **食べる(`eat_*`)**: その食料品を持っていて、満腹が 0.85 未満なら選べる。その場で食べる。食べ始めるときに持ち物が1個減る。
- **買う(`buy_*`)**: コンビニの入口へ歩き、着いたときにお金を払い、手に入る。選びやすさは次の合計:
  - 空腹なほど強い(満腹の不足の2乗)。
  - 食料品の満腹が、不足分より大きいと、余る分は無駄になる。満腹 0.6 なら、お弁当よりおにぎりが有利。
  - すでに食料品を持っているときは、あまり買わない。
  - **好み**: 村人ごとに、食料品ごとの好み(±0.15)がある。
  - **値段**: 倹約家(`thrift`)ほど金額そのものを重く見る。お金が少ない人は、誰でも値段を気にする。
- **持ち物が足りないと選べない**(お金が足りないと買えない)。この判定は ai_cpu の汎用の仕組み。

### ai_cpu に足した汎用の仕組み

お金や食料品の意味は、ai_cpu は知らない。「持ち物(resources)」と「支払い・獲得」だけを提供した([ai_cpu/design.md](ai_cpu/design.md))。

| 仕組み | 内容 |
| --- | --- |
| `Agent.getResources()` / `addResource()` | 持ち物(お金・アイテム)の読み書き。保存・復元できる |
| `ActionSpec.costs` | 行動を始めるときに払うもの。足りないと選べない。着いてから始まる行動は、`engage()` で払う |
| `ActionSpec.gains` | 行動を終えたときに手に入るもの。途中でやめると手に入らない |
| `AgentView.resources` | 判断の関数から、持ち物が見える |

## 確認 (2026-11-22)

村人50人の8日分(1日目は除く)を描画なしで動かして集計した(`npm run economy-check`)。1日を5分(300秒)にした後の結果。

| 項目 | 結果 |
| --- | --- |
| 買った食料品(1人1日あたり) | お菓子 0.48 / おにぎり 0.58 / カップ麺 0.63 / サンドイッチ 0.39 / お弁当 0.38(全種類が買われた) |
| 食べた回数 | 買った回数とほぼ同じ(買ったものは食べられている) |
| 満腹の平均 | 0.56。ほぼ空腹(< 0.05)の割合 4.5% |
| お金 | 1人1日あたり、収入 約 ¥670 / 支出 約 ¥560。所持金の平均は ¥880 → ¥2,046(期間中の平均 ¥1,910) |
| お金がない(< ¥120)割合 | 1.1% |
| 倹約家の支出 | 倹約家 ¥508/日、ふつう ¥576/日、浪費家 ¥593/日(倹約家のほうが少ない) |
| 好み | いちばん好きな食べ物を買った割合 59%(偶然なら 20%) |

## 試行錯誤

1. **最初は、村人が飢え続けた**(約80%の時間が空腹)。原因は2つ。(a)畑仕事を始めても、働きの欲求が回復するとおしゃべりなどに負けて途中で抜け、賃金が入らなかった。賃金は終えたときに入るため。畑仕事の `inertia` を 0.5 にした。(b)買い物の動機が弱く、満腹が 0.1 近くまで下がらないと買いに行かなかった。動機を強めた。
2. **それでもお金が足りなかった。** 原因を調べると、1日が240秒(ゲーム内の1秒が6分)と短く、村の端から端まで歩くのに2〜3時間かかっていた。「畑へ行く → 働く → コンビニへ行く → 食べる → 寝る」が1日に収まらなかった。**1日を1200秒(等速で20分)にした。** あわせて、行動の長さと欲求の減る速さを「ゲーム内の時間」で書く形に直し、1日の長さを `game/src/time.ts` の1か所の定数で変えられるようにした。→ 空腹が約80% → 2%に。
3. **お金が増え続けた**(1日あたり収入 ¥1,500・支出 ¥920)。賃金を ¥1,200 → ¥800 に下げ、お金に余裕がある人は働かなくなる補正を足して、頭打ちになった。
4. **倹約度が買い物に効かなかった**(倹約家 ¥235、浪費家 ¥242)。値段の重みが、所持金で割る形だったため、お金持ちだと小さかった。金額そのものを倹約度で重みづける形にして、支出と買い物の回数に違いが出た。ただし、1回の買い物の値段や満腹1あたりの値段には、ほとんど差が出ていない(下の課題)。
5. **1日を長くしたあと、昼寝好きでない人まで昼寝をした**(1日に約0.5回)。空き時間の埋め草になっていた。昼下がり(12〜16時)以外は、よほど疲れていなければ昼寝しないようにした([03-sleep.md](03-sleep.md))。

## あとから変えたこと

- **1日を 1200秒 → 300秒(5分)にした。** 1日を短くすると、村の中を歩く時間が1日の中で相対的に長くなる。そこで、村人が歩く速さに、`WALK_SPEED_SCALE` の倍率をかけるようにした(1200秒で1倍、300秒で2倍。時間の比をそのまま掛けると走っているように見えるので、平方根で穏やかにした)。歩く速さの倍率を変えて試した結果(1日300秒):

  | 歩く速さ | 満腹の平均 | ほぼ空腹の割合 |
  | --- | --- | --- |
  | ×1(補正なし) | 0.48 | 6.6% |
  | ×2(採用) | 0.56 | 4.5% |
  | ×3 | 0.59 | 3.7% |
  | ×4 | 0.61 | 2.6% |

  行動の長さを「ゲーム内の時間」で書いたので、1日を240秒にしたときのような飢えは起きず、補正なしでも成り立った。
- **食料品の買い方**: 1日が短くなっても、1日に食べる量は同じ。1回あたりの食べる時間・買う時間は、等速で見ると1〜4秒と短い。

## 残っている課題

- **お金の使い道が食料品だけ。** お金が頭打ちになるのは、使い道が少なく、働く動機を下げて調整しているため。服・家具・娯楽・貯金など、使い道が増えると変わる。
- **倹約家の違いが小さい。** 倹約家は買い物の回数が少ないだけで、安い物を選ぶ傾向はまだ弱い。
- **好みが強すぎる**(61%)。値段・空腹・好みの重みづけは、まだ調整の余地がある。
- **コンビニの中が見えない。** 入口で買うだけで、中に入らない。店員もいない。24時間営業のため、夜に買う村人が出る(夜更かしの村人には自然)。
- **在庫・価格変動がない。** 売り切れ、値上げ、品ぞろえの違いなど。
- **仕事が畑仕事だけ。** 村人の職業(コンビニの店員、農家など)がない。賃金は全員同じ。
- **お金に困ったときの行動がない。** 空腹でお金もない村人は、いまは畑仕事をするだけ。借りる・もらう・盗む、などの人間らしい反応は、人間関係と合わせて考える。
- **プレイヤーには空腹がない。** 買った食料品は、持ち物に入るだけ。プレイヤーの欲求は、次のテーマの候補。
- **ポーズ中は歩けない。** 世界の時間と一緒にプレイヤーの移動も止まる。
