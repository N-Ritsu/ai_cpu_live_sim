# 良い行動(ゴミ拾い・寄付・贈り物・交換)と、罰金・逮捕の「ばれ方」

「1つずつ整理する」の5番目。村人に「良い行動」を足した。あわせて、ポイ捨ての罰金が即時かどうかと、「ばれなかったら罰金も逮捕もされない」ことを確かめた。

## 1. ポイ捨ての罰金は即時か / ばれなかったらどうなるか

**答え: 即時になっている。ただし、巡査に見られたときだけ。** 見られなければ、罰金も手配も逮捕もない。

- ポイ捨てをした瞬間に、**12m以内に巡査がいて(家の外に出ていて)見ていたら、その場で、所持金から罰金 ¥100 が引かれる。**
- 見ていたのが巡査でなく村人なら、罰金にはならない(説教しに来る人がいるだけ)。
- どの巡査にも見られなければ、罰金はない。ポイ捨ては軽い違反なので、手配・逮捕にもならない。
- 万引き・すりなどの犯罪も、「ばれた」ときだけ手配になる(巡査の目撃・歩いて来た通報・防犯カメラ)。ばれなければ、手配にならず、逮捕もされない。

### 確認

確認ツールで、数字が食い違わないかを見る形にした(`npm run crime-check`)。村人50人・9日分。

| 項目 | 結果 |
| --- | --- |
| ポイ捨て | 65件: 巡査に見られた 20件(罰金 20件) / 見られなかった 45件(罰金 0件) |
| 罰金の件数 = 巡査に見られた件数か | OK |
| 重い犯罪 | 手配になった 84件 / 気づかれず・何もされず 4件 |
| 手配なしで逮捕した件数 | **0件**(0 のはず) |
| 逮捕 ≦ 手配か | 逮捕 83件 ≦ 手配 84件: OK |

### 見つかった不具合

この確認で、**手配されていない人を逮捕した件数が6件**あった。巡査と犯人の喧嘩で、巡査が勝ったとき、手配されているかを確かめずに逮捕していた。**手配されている人だけを逮捕する**ように直した(手配されていなければ、巡査が取り押さえるだけ)。

## 2. 良い行動

### 心身の充足

「心身が充足している」ことを、**充足度**(0〜1)で表した: 欲求(満腹・元気・社交・働き)の平均と、平静(精神状態)を半分ずつ。良い行動は、充足度が高い人ほどしやすい。充足度が 0.55 未満の人は、贈り物・寄付の機会を探さない(自分に余裕がない)。

### ゴミ拾い(既存の行動を強化)

落ちているゴミを、拾いに行く。次の人ほどしやすい。

- **正義感が強い人**(重みを 0.8 → 1.6 に強めた)
- マナーにうるさい人(重みは 0.9 → 0.6 に下げた)
- **心身が充足している人**(重みを 0.6 → 1.0 に強めた)

### 寄付・贈り物

- 贈る人は、近く(25m以内)の人の中から、相手を選ぶ。
- **お金に困っている人**: お金が ¥100 未満で、食料品を持っておらず、おなかが空いている人。贈る人が食料品を持っていれば、相手が好きなものをあげる。お金に余裕(¥500 以上)があれば、¥100〜250(所持金の4分の1まで)を寄付する。
- **友達へのプレゼント**: 困っていなくても、友達(お互いの感情が +25 超)には、食料品を2個以上持っているとき、1個あげる。
- 実際に贈るかどうかは、**気前のよさ**と、心身の充足度、相手との仲で決まる確率:

```
贈る気持ち = 2.0 × (気前のよさ − 0.5) + 2.0 × (充足度 − 0.7) + (困っている相手なら +0.25) + 1.2 × 相手との仲 − 0.25   (0〜0.8に収める)
気前のよさ = 0.6 × 正義感 + 0.25 × 優しさ(協調性) + 0.15 × (1 − アウトロー度)
```

- 正義感が強い人は、気前がよく、**特に寄付・贈り物をしやすい**。アウトローは、あまりしない。
- もらった人は、あげた人を好きになる(+0.2。困っていたときは大きく)。気持ちも落ち着く(平静が上がる)。あげた人も、少し親しみを持つ(+0.05)。見ていた人は、あげた人に好意を持つ(優しい人ほど。アウトローは、あまり感心しない)。
- 同じ人が続けて受け取らないように、もらったあと12時間(ゲーム内)は、次の贈り物の対象にならない。

### 食料品の交換

- **友達どうし**(お互いの感情が +20 超)で、相手の持っている食料品のほうが、お互いに好みのとき、近く(14m以内)で交換する。
- 友達でなければ、交換しない。

### 友達

- 友達は、おしゃべりで仲良くなる(同じ場所でおしゃべりした人どうしが、お互いに +0.05)。感情は、4日(ゲーム内)で半分に薄れる。
- 村人50人で、友達(お互いに +25 超)の組は、約 40〜115組(1人あたり 1.6〜4.6人)。

### 実装の仕組み

- 誰が誰に何をあげるか(機会)は、`Society` が、村人を順番に見て決める(ゲーム内の30分ごとに、ひとりずつ)。あげる行動(`give`)・交換する行動(`trade`)は、説教・通報と同じく、「きっかけ」の持ち物を使って、ai_cpu の行動にした。
- あげる人は、相手のところへ歩いて行き、近づいたら渡す。ai_cpu は、お金・食料品・友達を知らない(ai_cpu に足したものはない)。

## 3. 確認 (2026-11-22)

村人50人の9日分(1日目は除く)。

| 項目 | 結果 |
| --- | --- |
| 贈り物・寄付 | 54件(お金 26 / 食料品 28)・交換 3件・失敗 3件 → 1日あたり 約 6.3件 |
| 贈り物の相手 | お金に困っている人 36件 / 友達 18件 / その他 0件 |
| 心身の充足度と良い行動(1人1日あたり) | 充足度が低い(< 0.70)人 0.04回 / ふつう(0.70〜0.85) 0.28回 / 高い(> 0.85) 0.38回 |

**特性ごとの違い**: 行動した人の特性の平均を、村人全体の平均と比べた。

| 特性 | ゴミ拾いをした人 | 贈り物をした人 | 村人全体 |
| --- | --- | --- | --- |
| 正義感 | **0.62** | **0.56** | 0.46 |
| マナー意識 | 0.53 | 0.45 | 0.47 |
| 優しさ(協調性) | 0.50 | 0.57 | 0.54 |

- ゴミ拾いも贈り物も、正義感が強い人ほど多い。優しい人は、贈り物が多い。
- 正義感が強い人(3人・人口の6%)は、ゴミ拾いの10%・贈り物の11%を担っている。
- アウトローは、ほとんど良い行動をしない(ゴミ拾い 1%)。

## 試行錯誤

1. **贈り物の失敗が、成功より多かった**(失敗 81件・成功 55件)。調べると、贈る人が、相手に近づく前に「渡し終えた」ことになっていた。行動を選んだ最初の1フレームでは、追う相手がまだ決まっておらず、「いまの位置が目的地」になって、その場で「着いた」と扱われていた。**行動を選ぶ時点で、追う相手を決める**ように直した(失敗 81件 → 2件)。
2. **同じ不具合は、説教・喧嘩・逮捕にもあった**。説教は、静かに失敗していて、実際は件数が多かった(134回 → 155回)。治安の数字も少し変わった([06-feelings.md](06-feelings.md) の数字は、この修正前のもの)。
3. **正義感の効果が、見えなかった。** 正義感が強い人の、ゴミ拾い・贈り物の割合が、人口比と同じだった。原因は2つ。(a) ゴミも、困っている人も、数が限られていて、誰かが先にやってしまうため、1人あたりの回数では差が出ない。そこで、「人口に対する取り分」と「行動した人の特性の平均」で比べるようにした。(b) 贈り物の気前のよさで、優しさ(協調性)の分散が大きく、正義感が埋もれていた。正義感の重みを上げ、確率が上限に張りつかないようにした。
4. **贈り物が1日16件**と多く、お金に困った同じ人に集中した。困っている人の条件を厳しく(お金 ¥100 未満・食料品なし・おなかが空いている)し、もらったあと12時間は対象外にし、確率を下げた(→ 1日あたり約6件)。
5. **友達が多すぎ / 少なすぎ**(156組 / 19組)。おしゃべりでの親しくなり方と、感情が薄れる速さを調整した(→ 40〜115組。まだ、乱数でぶれる)。

## 残っている課題

- **お金のやりとりが、寄付と贈り物だけ。** お金を貸す・借りる・返す、お礼、恩返し(もらった人があげた人に何かを返す)はない。
- **交換がまれ**(9日で3件)。お互いに食料品を持っていて、好みが逆で、仲が良い、という条件が重なることが少ない。
- **良い行動の種類が少ない。** ほかにも、道案内・手伝い・看病・差し入れ・あいさつ・席をゆずる、などが考えられる。
- **贈り物の見た目がない。** 渡す動作・吹き出しは、ない(ログに出るだけ)。
- **友達の数は、まだ乱数でぶれる。** 友達グループ(派閥)・恋人・親友・敵対、などの関係の種類は、ない。
- **罰金が、巡査の目の前でなくても即時。** 12m以内なら、巡査が近づく前に、その場で引かれる。巡査が近づいて、切符を切る(説教や口論になることもある)、は、まだない。
- **お金持ちほど寄付をする、などの経済的な理由**は、まだ入っていない。
