# 効果音の差し替え(効果音ラボ)

最初の効果音は、Web Audio で合成した音([09](09-layout-player-talk.md) の「効果音」)。**聞いた結果、全般に品質が足りなかった**ので、素材サイト「効果音ラボ」の音に差し替えていく。

> 経緯: 最初は SFXMint(CC0 の効果音ライブラリ。Claude Code のプラグインがある)で、1日3音ずつ取る予定だった。ダウンロード数の制限があり、利用者が効果音ラボから自分で集めるほうが早いので、変更した。SFXMint 用に作った設定は、削除した。

## 仕組み

- 音のファイルは、リポジトリのルートの `se/`(利用者がダウンロードした元のファイル。git には送らない)にある。ゲームが読み込むのは、そのコピーの `game/public/sfx/`(英数字のファイル名)。
- `game/public/sfx/manifest.json` に、音の名前(`SfxName`)・ファイル・音量を書く。**書いていない音は、これまでの合成音のまま**なので、1音ずつ差し替えられる。同じ音に複数のファイルを書くと、ランダムに選ぶ(再生の速さも少しばらつかせる)。

```json
{ "hit": { "files": ["punch.mp3"], "volume": 0.9 } }
```

- 足音と環境音は、**くり返し流す**。歩いている間だけ流し、止まると消える(なめらかに音を上げ下げ)。
- ダウンロードしたとき付いてくる `*:Zone.Identifier` ファイル(Windows の「ダウンロードしたファイル」の印)は、不要なので消した。

## 割り当て済み

| 音(`SfxName`) | ファイル(`se/` の元の名前) | 使う場面 |
| --- | --- | --- |
| eat | お菓子を食べる1.mp3(4.1秒) | 食べる(食料品ぜんぶ同じ音。「飲む.mp3」は、飲み物がないので使わない) |
| door | ドアを開ける1.mp3(1.1秒) | 家・ビルの出入り |
| coin | レジスターで精算.mp3(0.9秒) | 買う・贈る・交換 |
| hit | 小パンチ.mp3(0.4秒) | パンチ(空振りも、当たったときも、同じ音)・喧嘩の始まり |
| alarm | 警官のホイッスル2.mp3(1.4秒) | 手配・逮捕・勾留・罰金の知らせ |
| walk | 芝生の上を歩く.mp3(17秒・くり返し) | 歩いている間 |
| run | 芝生の上を走る.mp3(9.6秒・くり返し) | 走っている間 |
| ambient | 動物園.mp3(113秒・くり返し) | **ふつうの環境音**として、村のどこでも、いつも流す(音量は小さめ)。建物の中では、さらに小さく |

## まだ合成音のまま(足りない音)

毎回聞く音を優先。

| 音 | 場面 | 欲しい音の例 |
| --- | --- | --- |
| menu / select / deny | メニューを開く・選ぶ・選べない | 決定音・カーソル音・キャンセル音(システム音) |
| toast | ふつうの知らせ | 通知音・ポップアップ音 |
| blip | 会話の吹き出し | 短い会話音・ぽこぽこ音 |
| whoosh | すり・万引きの動き | 衣ずれ・すばやい動きの音(パンチの空振りは、パンチの音に統一したので不要) |
| throw | 物を投げる | 投げる音・風切り音 |
| litter / bin | ポイ捨て・ゴミ箱・拾う | ゴミを捨てる音・缶の音 |
| praise / insult | ほめる・けなす | 明るい音(ほめる)・低い不快音(けなす・怒られる) |
| work | 仕事の開始 | キーボード・書類・作業音 |
| sleep | 睡眠の開始 | あくび・ふとんの音・やすらぐ音 |
| map | 見下ろし視点の開閉 | 切り替え音 |

## 確認していないこと

- 実際に鳴らした聞こえ方(音量のバランス・くり返しの継ぎ目)。ファイルが取得できること(開発サーバーから読めること)と、型の検査だけ確認した。
- 足音は、止まってから約0.4秒で消える。歩き始めの位置はランダム。
