# 効果音の差し替え(SFXMint)

最初の効果音は、Web Audio で合成した音([09](09-layout-player-talk.md) の「効果音」)。**聞いた結果、全般に品質が足りなかった**ので、[SFXMint](https://sfxmint.com)(CC0 の効果音ライブラリ)の音に、**何日かに分けて**置き換えていく。

## 仕組み

- Claude Code のプラグイン `sfxmint`(MCP サーバーと、使い方の手引き)を、このプロジェクトの設定(`.claude/settings.json`。git には送らない)で有効にした。音を探す・試聴する・ダウンロードするのは、Claude Code から行う。
- ゲーム側(`game/src/audio.ts`)は、`game/public/sfx/manifest.json` に書いた音のファイルを読み込んで鳴らす。**ファイルがない音は、これまでの合成音のまま**なので、1音ずつ置き換えられる。同じ音に複数のファイルを書くと、ランダムに選ぶ(速さも、少しだけばらつかせる)。

```json
{ "hit": { "files": ["hit1.wav", "hit2.wav"], "volume": 0.8 } }
```

## 制限(無料の範囲)

- ダウンロードは **1日3音まで**(無料アカウントの API キーが必要。キーは、利用者自身が設定する。リポジトリには置かない)。検索・試聴は、キーなしで1日20回まで。
- 音は CC0(商用利用可・表記不要)。ただし、AI 生成または合成の音なので、公開するときは、公開先の AI 申告欄に書く。

## 置き換えの進み具合

置き換える音(`SfxName`)と、使う場面。置き換えたら、音のファイル名と取得元の ID を、右の欄に書く。

| 音 | 場面 | 状態 |
| --- | --- | --- |
| step | 歩く・走る(足音) | 未 |
| whoosh | パンチの空振り・すり | 未 |
| hit | パンチが当たる・喧嘩 | 未 |
| throw | 物を投げる | 未 |
| eat | 食べる | 未 |
| coin | 買う・贈る・交換 | 未 |
| door | 家・ビルの出入り | 未 |
| menu / select / deny | メニューの開く・選ぶ・選べない | 未 |
| toast | 知らせ | 未 |
| alarm | 手配・逮捕・勾留 | 未 |
| blip | 会話の吹き出し | 未 |
| praise / insult | ほめる・けなす | 未 |
| bin / litter | ゴミ箱・ポイ捨て・拾う | 未 |
| map | 見下ろし視点の開閉 | 未 |
| work / sleep | 仕事・睡眠の開始 | 未 |

優先順: 毎回聞く音(足音・メニュー・パンチ・知らせ)から。
