# 3D試作 (game/)

「村人50人+多くの物」を、ブラウザの3Dで動かして、重さと村人の振る舞いを確かめるための試作。

## 動かし方(ローカル)

```bash
cd game
npm run dev      # http://localhost:5173/
```

| URL の指定 | 意味 |
| --- | --- |
| `?n=200` | 村人の数(標準 50)。重さを試す |
| `?speed=4` | 時間の速さ(1・4・16・64)。遊んでいる間は 1〜4 キーでも変えられる |
| `?hour=20` | 開始時刻(標準 9 時) |
| `?px=9&pz=0` | プレイヤーの最初の位置(確認用) |
| `?pitch=0.1` | 視線の上下(ラジアン。確認用) |
| `?menu=1` | 行動メニューを開いて始める(確認用) |
| `?talk=1` | いちばん近い村人との会話を開いて始める(確認用) |
| `?paused=1` | ポーズしたまま始める(確認用) |
| `?yaw=3.14` | 視点の向き(ラジアン。0 で北向き。確認用) |
| `?warmup=600` | 最初に、画面なしで 600 秒ぶん(ゲーム内の約2日)先に進めておく(ログ・感情・事件の確認用) |

操作(1人称視点): クリックで視点操作を始める(Esc で解除) / WASD で歩く / Shift で走る / マウス・矢印キーで見回す / **E で行動メニュー**(場所・目の前の村人に応じて、CPU と同じ行動ができる) / T で目の前の村人と話す / Backspace で行動をやめる / P で時間を止める / 1〜4 で時間の速さ。目の前の村人の中身(欲求・性格・持ち物・人への感情・最近したこと)が、画面に出る。詳細は [09-layout-player-talk.md](09-layout-player-talk.md)。

## 何が入っているか

- **世界**: 広場と井戸、コンビニ(食料品)、交番(警察)、会社のビル3棟、牧場(家畜小屋・動物)、ゴミ箱、畑(日雇い)、住宅の輪(1軒に2人)、周りの森(木400本・岩150個)。昼夜があり、1日はゲーム内で300秒(等速で5分)。
- **村人**: 標準50人。性格(5つの特性)・睡眠の個性([03-sleep.md](03-sleep.md))・欲求の初期値が一人ずつ違う。`ai_cpu` が「買う・食べる・睡眠・昼寝・おしゃべり・畑仕事・散歩・ゴミ捨て・ポイ捨て・ゴミ拾い・万引き・すり」などから選び・贈り物・交換(巡査はパトロール・逮捕)、ゲーム側が目的地まで歩かせる。家・井戸・コンビニをよける。
- **プレイヤー**: CPU と同じ村人の1人(1人称視点)。CPU と同じ行動を、行動メニューからとれる。村人と会話もできる。
- **画面の左上**: 時刻、FPS、描画呼び出し回数、三角形の数、1秒あたりのAI更新数、手配中の人数・落ちているゴミの数。その下に、治安のログ(ポイ捨て・万引き・通報・逮捕・勾留)。

## 描画の工夫(いま入っているもの)

- 村人は、体・頭・鼻の3つの `InstancedMesh`。**50人でも描画呼び出しは3回**。
- 家(壁・屋根・扉)、木(幹・冠)、岩、作物もインスタンシング。
- 材質は軽い `MeshLambertMaterial`。影は太陽1つ、プレイヤーの周りだけ。

## 測った結果 (2026-11-22)

| 項目 | 結果 |
| --- | --- |
| 画面 | 描画呼び出し 34回、三角形 約8.5万。ソフトウェア描画(GPUなし)の自動ブラウザで約90 FPS |
| ロジック(`sim-check`、描画なし) | 村人50人: 1ステップ(1/10秒)あたり約 0.1 ms。村人300人: 約 1.9 ms |

- GPUなしのソフトウェア描画でも90 FPS 出たので、描画側は余裕がある。実際のGPUや、スマホでの測定はまだ。
- `?n=300` のときの見た目と FPS は、まだ実ブラウザで確かめていない。

## わかった課題・次にやること

- **見た目**: 村人はカプセルと球だけ。向きは鼻の小さな箱でしか分からない。歩きのアニメーションは上下のはずみだけ。
- **寝ている村人**: 家に入らず、玄関の前で横になる。家の中に入る動きが要る。
- **村人どうしの衝突**: よけ合わない(重なって歩く)。
- **プレイヤーが村人と関われない**: 話しかける・一緒に何かをする、が次の大きな課題。
- **「本物の人間らしさ」**: いまは欲求と性格だけで、同じ行動の繰り返しに見える。人間関係・記憶・習慣・気分が必要([ai_cpu/design.md](ai_cpu/design.md) の「これから足すもの」)。
- **欲求の調整**: 1日が短いと、村人が1日中移動して欲求が尽きたままになった。1日を1200秒にして、満腹はほぼ尽きなくなった。その後、1日を300秒(5分)にしても、歩く速さの補正(×2)で成り立つ([04-economy.md](04-economy.md))。
- **スマホ**: 対象にするかを決めてから、性能の目標を決める。
