# 対人感情・説教・喧嘩・追い詰められた犯人

「1つずつ整理する」の4番目。村人どうしの「好き・嫌い」(対人感情)を足し、それを元に、説教・通報・喧嘩、追い詰められた犯人の反応(投降・逃走・反撃)を作った。あわせて、警察の収入を整えた。

## 1. 警察の収入

依頼「警察はパトロールで収入を得るようになってる?」への答え: **前の版でも、パトロール1回につき ¥20 が入る設定だった。** ただし、実測すると1日あたり約 ¥130〜220 で、畑仕事の村人(約 ¥800)より、ずっと少なかった。そこで整えた。

- **パトロール1回の給料を ¥60 に**(収入の中心)。
- **逮捕を成功させたときの手当 ¥100** を足した(取り逃がしには出ない)。
- 結果(村人50人・9日分): 巡査Aは 約 ¥936/日(パトロール 10.2回 + 逮捕 3.2回)、巡査Bは 約 ¥807/日(パトロール 7.3回 + 逮捕 3.7回)。畑仕事の約 ¥800/日と、同じくらい。
- 巡査Bのほうが少ないのは、勤務が 11〜22時で、夜の睡眠の時間帯が重なるため。

## 2. 対人感情

村人は、他の人ごとに「感情」(-1 の悪意 〜 +1 の好意)を持つ。ai_cpu に、汎用の仕組みとして足した(下の「ai_cpu に足した仕組み」)。

### 感情が動くきっかけ

他の人の行動を、近く(10m以内、遠いほど弱い)で見たときに動く。

| 見た行動 | 見た人の感情の変化 |
| --- | --- |
| マナーの良い行動(ゴミを捨てる・ゴミ拾い) | 好意が増える |
| マナーの悪い行動(ポイ捨て) | 悪意が増える |
| 犯罪(万引き・すり) | 悪意が増える(被害者は、さらに強く) |
| 暴力(喧嘩で手を出した) | 悪意が増える |
| 巡査が犯人を逮捕 | 巡査への好意が増える |
| 同じ場所でおしゃべり | お互いに、少し好意が増える |

- 変化の大きさは、見た人の性格で変わる。マナーにうるさい人ほど、マナーの良し悪しに強く反応する。正義感が強い人ほど、犯罪・暴力・逮捕に強く反応する。
- **アウトローは、逆向きに動く。** マナーの悪い人・犯罪者に好意を持ち、マナーの良い人にはあまり好意を持たず(少し悪意)、警察には悪意を持つ。アウトロー度の高さに応じて、向きが連続的に反転する(0.3 以下は反転なし、0.7 以上で完全に反転)。
- 感情は、2日(ゲーム内)で半分に薄れる。

### 確認

村人50人の9日分で、グループごとの感情の平均を取った(-100〜+100)。

| 見る人 \ 見られる人 | マナー悪 | アウトロー | マナー良 | 巡査 |
| --- | --- | --- | --- | --- |
| マナーにうるさい | -9 | -5 | +8 | +9 |
| 正義感が強い | -3 | -5 | +8 | +9 |
| **アウトロー** | **+2** | **+4** | -3 | **-13** |
| マナーを守らない | -3 | -2 | +2 | +4 |
| ふつう | -1 | 0 | +8 | +6 |

- マナーにうるさい人は、マナーの悪い人を嫌い、良い人を好む。
- アウトローだけ、マナーの悪い人・アウトローに好意(プラス)を持ち、巡査を嫌う。設計どおり。
- 平均が小さく見えるのは、一度も見たことのない相手(0)も含めた平均のため。

## 3. 説教と通報

悪事を見た人は、見た人の性格で、行動を起こす。

| 行動 | する人 | 内容 |
| --- | --- | --- |
| **説教**(`scold`) | 正義感が強い人・マナーにうるさい人。その人を嫌っているほど、する。アウトローはしない | 悪事をした人のところへ歩いて行って、注意する |
| **通報**(`report`) | 犯罪を見た、正義感が強い人。被害者は、さらにする | 交番まで歩いて行って、通報する。通報が着いて、はじめて「手配」になる |

- 巡査が見ていたときは、これまでどおり、巡査がその場で対応する(ポイ捨ては罰金、犯罪は手配)。
- 以前は、見た瞬間に自動で通報されていたが、**歩いて交番へ行く時間がかかるようになった。**
- 説教・通報は、悪事を見たあと3時間(ゲーム内)たっても行けなければ、やめる。

## 4. 説教された人の反応(逆上・喧嘩)

説教されると、次のどれかになる。

- **逆上して喧嘩になる。** 短気な人(`temper`)・アウトローほど、逆上しやすい。精神状態が悪い(下の「精神状態」)・説教した人を嫌っている・マナーを守らない・後ろめたい(手配中)ときも、逆上しやすい。正義感が強い人は、受け入れやすい。
- **謝る。** マナーを守る人・正義感が強い人ほど謝る。お互いの感情が少し良くなる。
- **無視する。** 説教した人への悪意が増える。

**喧嘩**: 逆上した人と説教した人が、向き合って殴り合う(体が小刻みに揺れる)。強さは、アウトロー・短気・体力・運で決まる。負けた人はけがをして、家に帰って休む(休養。平静も取り戻す)。2人とも気が動転し、お互いへの悪意が強まる。見ていた人は、手を出した人への悪意が増え、正義感が強い人は通報する。巡査が近くで見ていたら、手を出した人は暴行で手配される。

### 精神状態(平静)

- 新しい欲求「平静」(1 が落ち着いた状態)を足した。叱られる・喧嘩・追い詰められる・勾留されるなどで下がり、時間とともに戻る(1日で 0.8 回復)。
- 「精神的な余裕のなさ」= 平静の低さ(6割)+ 空腹・疲れ(4割)。これが高いと、逆上しやすく、追い詰められたときに反撃・逃走に出やすく、犯罪にも少し手を出しやすい。

### 新しい性格「短気」(キレやすさ)

- 自分で足した特性。釣り鐘型で、0.75 超(「キレやすい」)は約6%(50人なら3人)。

### 確認

| グループ | 説教された回数 | うち逆上 |
| --- | --- | --- |
| アウトロー | 18回 | 44% |
| キレやすい(短気 > 0.75) | 7回 | 29% |
| 短気な上位3分の1 | 64回 | 19% |
| 短気でない3分の2 | 70回 | 13% |
| それ以外 | 109回 | 10% |

- 全体では、説教 134回 → 謝った 33 / 無視 80 / 逆上して喧嘩 21(約16%)。
- 喧嘩は 21回(うち9回は、追い詰められた犯人と巡査の喧嘩)。

## 5. 追い詰められた犯人

手配された犯人を、巡査が追いかけ、7m以内まで近づくと、犯人は**投降・逃走・反撃**のどれかを選ぶ。性格と精神状態で、確率が変わる。

| 反応 | なりやすい人 |
| --- | --- |
| 反撃 | アウトロー・短気・精神状態が悪い人。正義感が強い人はしにくい |
| 逃走 | 精神状態が悪い人。一度逃げて追われ続けた人は、だんだん逃げなくなる |
| 投降 | 正義感が強い人・マナーを守る人。精神状態が悪い人・アウトローはしにくい。追われ続けるほど、観念しやすい |

- **逃走**: 巡査から遠ざかる方向へ、ふだんの1.45倍の速さで走り、しばらく身を隠す。巡査は追い続け、3時間(ゲーム内)追っても捕まえられなければ、断念する(その後 1.5時間は追わない。見つけたら、また追う)。
- **反撃**: 巡査と喧嘩になる。巡査は訓練を受けているので、ふつう勝つ(勝つと逮捕。公務執行妨害で逮捕歴がもう1つ増える)。負けると、巡査はけがをして休み、犯人は逃げる。
- 巡査は、新しい手配の犯人には、距離に関係なく向かう。古くなった手配は、近く(45m以内)で見つけたときだけ向かう。

### 確認

| グループ | 追い詰められたとき(投降 / 逃走 / 反撃) |
| --- | --- |
| アウトロー | 2 / 8 / 6 |
| それ以外 | 22 / 10 / 3 |

- 全体: 投降 24 / 逃走 21 / 反撃 9。巡査が返り討ちにされたのは、3回。
- アウトローは逃走・反撃に、普通の人は投降に偏る。

## ai_cpu に足した仕組み

- **対人感情(`relations`)**: 村人ごとに、他の人への感情(-1〜1)を持つ。`getRelation` / `getRelations` / `addRelation`。保存・復元できる。`AgentView.relations` で、判断の関数からも見える。`Tuning.relationHalfLifeSec` で、時間とともに薄れる(半減期)ようにできる。
- **欲求の外部調整(`adjustNeed`)**: ゲームの出来事で、欲求を増減できる(叱られて平静が下がる、など)。平静のように「回復していく欲求」は、減る速さを負にして表す。
- **性格の参照(`getPersonality`)**: 読み取り専用。
- ai_cpu は、説教・喧嘩・警察を知らない。感情の変わり方や反応の確率は、すべてゲーム側(`game/src/feelings.ts`)の計算。

## 試行錯誤

1. **「逮捕の回数」が多すぎるように見えた**: 逮捕の「行動」の完了回数は、取り逃がしも含む。成功した逮捕だけを数えるようにした(警察の収入の計算で発覚)。
2. **追い詰められた犯人の反撃が約3割**と多かった。犯人の多くは「ややアウトロー・空腹でストレスが高い」人で、反撃の重みが大きかった。反撃の重みを下げ、投降の重みを上げた(反撃 約 9%)。
3. **普通の人の逮捕歴が多かった**(1人あたり約 1.9回)。原因は、ストレスによる犯罪の加点が大きかったことと、罰金で所持金が尽きて、また犯罪に走ること。ストレスの加点を 0.15 → 0.08 に、罰金を「所持金の半分まで」にした。
4. **逮捕までの時間が長くなった**(1.6 → 3.4 時間)。犯人が逃げる・巡査が返り討ちにされる・通報に時間がかかるようになったため。意図した変化。

## あとから直したこと(良い行動の追加時)

行動を選んだ最初の1フレームで、追う相手が未設定のまま「着いた」と扱われる不具合があった(説教・喧嘩・逮捕は、静かに失敗することがあった)。**行動を選ぶ時点で、追う相手を決める**ように直した([07-good-deeds.md](07-good-deeds.md))。修正後の数字(村人50人・9日分): 説教 155回(謝った 43 / 無視 89 / 逆上して喧嘩 23)、喧嘩 38回(うち巡査との喧嘩 18)、巡査が返り討ち 1回、追い詰められた犯人は 投降 22 / 逃走 34 / 反撃 18、犯罪 1日あたり約 7.8件、逮捕 83件(手配から平均 4.3 時間)。この文書の他の数字は、修正前のもの。

## 残っている課題

- **追跡の断念は、実装したが、集計では一度も起きなかった**(捕まえるまでが短く、3時間を超えない)。コードの経路は、まだ動作を確かめていない。
- **巡査が2人のまま。** 人口が増えると追いつかない。
- **感情の使い道が少ない。** 感情は、説教・通報・逆上の確率にだけ効く。誰とおしゃべりするか・誰を避けるか・友達・恋人・仲間・集団(派閥)などには、まだ使っていない。
- **感情の種類が1つだけ**(好き嫌い)。怒り・恐れ・恨み・感謝・尊敬など、種類のある感情は、ない。
- **噂が広がらない。** 感情は、自分で見たことだけで決まる。うわさ・伝聞はない。
- **復讐がない。** 喧嘩に負けた人や、通報された人が、仕返しをすることはない。
- **けがの重さ・病気がない。** 負けると「けが」で一律に休む。
- **プレイヤーはまだ関われない。** 説教される・通報される・喧嘩に巻き込まれる、などは、プレイヤーには起きない。
- **ログの文章が単調。** 台詞・吹き出しなどはない。
