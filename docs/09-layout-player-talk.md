# 村の配置・プレイヤー(1人称)・対話

「1つずつ整理する」の7番目。村の配置を見直して整理し、プレイヤーを1人称視点にして、CPU と同じ行動を全部とれるようにし、互いに対話する機能を足した。

## 1. 村の配置の見直し

道路を通し、役割ごとに区画を分け、建物の向きをそろえた(北が上)。

```
                    [会社A]   [会社B]   [会社C]        ← 北: オフィス街(通りに面して一列、入口は南向き)
          ─────── 会社の前の通り ───────
   [交番]  ─────────  広場(井戸)  ─────────  [コンビニ]   ← 東西の大通りの北側に、向かい合う
   ━━━━━━━━━━━━━━━━━━━━━━━━━┿━━━━━━━━━━━━━━━━━━━━━━━━━  (東西の大通り)
   [畑]            (南北の大通り)               [公園]       ← 南: 畑(西)・公園(南東)
   住宅は、外周に輪になって並ぶ(入口は、すべて村の中心向き)。牧場は、輪のすぐ外(南西)。
```

- **道路**: 東西の大通り、南北の大通り、会社の前の通り(いずれも見た目だけ。村人は、道の上を歩く必要はない)。
- **広場**(半径9m)の周りに、コンビニ(東)と交番(西)を、大通りの向かい合わせに置いた。コンビニ・交番・ビルの入口は、南向き。
- **オフィス街**(北): ビル3棟を一列に。会社の前の通りに面している。
- **畑**(南西)・**公園**(南東。池・木・ベンチ。新しく追加)。
- **住宅**: 外周の輪に並べる。ほかの建物・畑・公園に重なる場所は、飛ばして、次の輪へ回す(以前は、建物に重なっても並べていた)。住宅の壁・屋根は、中に入ったときに内側が見えるように、両面を描く。
- **牧場**: 輪のすぐ外(南西)。畜産家は、住宅から歩いて向かう。
- コンビニ・交番・ゴミ箱・巡査の経路・店番や勾留の場所を、新しい位置に合わせて更新した。

### 重なりの確認ツール

`npm run layout-check`: 建物どうしの重なり、目的地・経路の点が建物の中に入っていないか、全体の地図(文字)を出す。

- 村人51人(住宅26軒): 建物の重なり **0件**、建物の中に入った目的地・経路の点 **0件**。
- 村人201人(住宅101軒): 同じく 0件・0件。

## 2. プレイヤー(1人称視点・CPU と同じ行動)

### 仕組み

プレイヤーは、CPU と同じ「村人」の1人(欲求・持ち物・職業・感情・手動の ai_cpu エージェントを持つ)。行動は、CPU と同じ ai_cpu の行動(`buy_*`・`steal_*`・`scold`・`give` など)を、プレイヤーが自分で始める形にした。

- そのため、持ち物の増減・出来事(目撃・通報・手配・逮捕・感情の変化)は、**CPU とまったく同じ処理**で反映される。たとえば、プレイヤーが万引きをすれば、店員・巡査・通報する村人に見つかり、手配され、巡査に追われ、逮捕され、交番で勾留される。CPU がプレイヤーを説教し、プレイヤーに贈り物をし、プレイヤーからすられることもある。
- ai_cpu に、**手動モード**(`setManual` / `start` / `cancel`)を足した。手動モードでは、次の行動を自分では選ばない(欲求の変化・行動の進行・感情の薄れは、ふだんどおり)。人間が選んだ行動には、CPU の「選べる条件」(追い詰められていないとすりができない、など)を当てはめない。
- 1人称視点: カメラは、プレイヤーの目の高さ。自分の体は描かない。

### 操作

| 操作 | 内容 |
| --- | --- |
| クリック | 視点操作を始める(マウスを取り込む)。Esc で解除 |
| WASD / Shift | 歩く / 走る |
| マウス・矢印キー | 見回す |
| **E** | **行動メニュー**を開く(場所・目の前の村人に応じた行動の一覧)。数字キーで選ぶ(1ページ8項目。9 で次のページ、0 で戻る・閉じる) |
| T | 目の前の村人に話しかける |
| Backspace | いまの行動をやめる |
| P / 1〜4 | 時間を止める / 時間の速さ(×1・×4・×16・×64) |

- 目の前(視線の先、10m以内)の村人の中身が、画面に出る。3.6m以内なら、その村人への行動ができる。
- メニューや会話を開いている間は、世界の時間が止まる。睡眠・仕事などの長い行動の最中は、時間が自動で速く進む(×16)。
- 画面の右下に、プレイヤーの所持金・持ち物・欲求(満腹・元気・社交・働き・平静)・職業・状態(手配中・けが)が出る。事件の知らせ(目撃した・盗まれた・説教された・もらった、など)は、画面の下に出る。

### CPU と同じ行動の一覧

| CPU の行動 | プレイヤーのやり方 |
| --- | --- |
| 買う(`buy_*`) | コンビニの前で E → 食料品を買う |
| 食べる(`eat_*`) | E → 持っている食料品を食べる(ゴミが出る) |
| 万引き(`steal_*`) | コンビニの前で E → 万引きをする…(犯罪) |
| ゴミを捨てる / ポイ捨て / ゴミ拾い | ゴミ箱の近く・どこでも・落ちているゴミの近くで E |
| 睡眠・昼寝・休養 | 自宅の前で E → 家に入る → 寝る・昼寝・休養(けがのとき) |
| 会社員の仕事(`office_work`) | 勤務先のビルの前で E → 出社する → 会社で仕事をする(勤務時間内) |
| 畜産家の仕事(`ranch_work`) | 牧場で E → 動物の世話をする(勤務時間内) |
| 店員の仕事(`clerk_work`) | コンビニの前で E → 店番をする(勤務時間内) |
| フリーターの日雇い(`gig`) | 畑の中で E → 畑の日雇いをする |
| おしゃべり(`chat`) | 広場で E → 広場でおしゃべりして過ごす。村人に話しかけて、会話もできる(下の「対話」) |
| 説教(`scold`) | 目の前の村人に E → 説教する |
| 贈り物・寄付(`give`) | 目の前の村人に E → 贈り物・寄付をする…(食料品・¥100・¥250) |
| 交換(`trade`) | 目の前の村人に E → 食料品を交換する…(親しくない人には断られる) |
| すり(`pickpocket`) | 目の前の村人に E → すりをする…(犯罪) |
| 喧嘩(`fight`) | パンチが当たると始まる(下の「追加の調整」)。ほかの人に喧嘩を売られたときも、自動で始まる |
| 通報(`report`) | 目撃した犯罪(画面に知らせが出る)を、交番の前で E → 通報する |
| 勾留(`detained`) | 逮捕されると、自動で交番へ連れていかれ、勾留される |
| 転職 | どこでも E → 転職する…(空きのある職業へ) |
| 逃走(`flee`) | 走って逃げる(Shift)。自動では逃げない |
| 散歩(`wander`) | 歩き回る |

- **プレイヤーにはない行動**: パトロール(`patrol`)・逮捕(`arrest`)は警官だけの行動で、プレイヤーは警官になれない(転職の候補にない)。
- 持ち物が足りないとき(お金がない、など)は、始められずに知らせが出る。

## 3. 対話

おしゃべりをしている村人どうし、またはプレイヤーと村人が、会話をする。**基本は、話すほど仲が深まる。たまに(1割ほど)言い争いになる。**

### CPU どうしの会話

- おしゃべり(`chat`)で、近く(5.5m以内)にいる2人が、会話を始める。
- 1ターン1.5秒で、あいさつ → あいさつの返事 → 話題(天気・食べ物・仕事・ニュース・悩み・噂話・褒める) → 返事 → ... → 別れのあいさつ、と進む。マナーを守る人は丁寧な言葉、そうでない人はくだけた言葉。村人の職業・好きな食べ物・空腹・疲れ・お金の様子が、話の中身に出る。
- 言葉は、頭の上に**吹き出し**で出る(近く26m以内。時間を ×16 以上にしているときは出さない)。
- **普通は、仲が深まる**(お互いの感情 +0.05、気持ちが少し落ち着く)。
- **たまに、言い争いになる**。言い争いの確率は、標準で約8%。
  - 上がる: 短気・精神的な余裕がない・もともと仲が悪い・マナーの感覚が違う・噂話をする
  - 下がる: 仲が良い・悩みを聞く・褒める
- 言い争い: 短気なほうが先に言い返し、相手も言い返す(吹き出しが赤くなる)。お互いの感情が -0.12、気持ちが乱れる(平静 -0.15)。**短気な2人は、言い争いが喧嘩に発展する**ことがある(35%)。

### プレイヤーと村人の会話

- 目の前の村人に T(または E → 話しかける)。話題を選ぶ: 世間話・仕事の話・食べ物の話・悩みを聞く・噂話・褒める。
- 相手が答える。**普通は仲が深まる**(お互いに +0.05。プレイヤーの「社交」が回復する)。3つ話すと、相手が「そろそろ行かなきゃ」と別れを告げる。
- **たまに言い争いになる**。そのときは、選ぶ: **謝る**(7割で仲直り)・**言い返す**(短気な相手だと、喧嘩になる)・**立ち去る**(少し仲が悪くなる)。
- 会話の最中、相手は立ち止まる。

メニューの項目を、画面なしで実際に選んで実行し、結果が CPU と同じ仕組みで反映されるかを見る。**25件すべて成功。**

- 買う(所持金 ¥1,000 → ¥850)・食べる(満腹 +0.4、ゴミ +1)・ゴミ箱に捨てる・ポイ捨て(地面のゴミ +1)・ゴミ拾い

- お金を寄付する(相手 ¥500 → ¥750、相手の感情 +0.16)・説教する・親しくない人には交換を断られる・友達と交換する

## 試行錯誤

1. **プレイヤーが始めた行動が、すぐ取り消された。** すりは、CPU の「追い詰められていないと選べない」条件があり、プレイヤーが始めても、次の更新で「できない行動」として取り消された。**手動モードでは、人間が選んだ行動に、この条件を当てはめない**ようにした(ai_cpu のテストも足した)。
2. **「行動中」の判定が古かった。** 行動を始めた直後は、表示用の値がまだ更新されておらず、「何もしていない」と判定され、行動が終わる前に次へ進んでいた。エージェントの現在の行動を、直接見るようにした。
3. **説教・贈り物の最中に、相手が歩き去った。** CPU どうしの説教は、相手を追い続けるが、プレイヤーの場合は、相手が離れて失敗した。**プレイヤーが話しかけた相手は、そのあいだ立ち止まる**ようにした。
4. **配置を変えたら、経済が崩れた。** オフィス街を北に離したため、会社員の通勤が長くなり、仕事が1日1.44回 → 1.0回に減った。収入が足りず、お金がない人が 23.6%、犯罪が 1日19件に増えた。**オフィス街を広場に近づけ**、通勤を短くし、さらに**給料を引き上げた**(会社員 ¥420 → ¥580 など。[08-jobs.md](08-jobs.md))。
5. **自動検証で、万引きの結果としてプレイヤーが手配・逮捕され、あとの検証(睡眠など)が中断した。** これは、CPU と同じ処理が働いている証拠。検証の順序を、犯罪を最後にするように直した。
6. **言い争いが多すぎた/少なすぎた**。基準を調整し、プレイヤーとの会話で約11%、CPU どうしで約4.5% に。

## 残っている課題

- **実際のマウス操作・歩く感触は、確かめていない。** 画面(静止画)で表示を確かめ、行動・会話は、画面なしの検証ツールで確かめた。マウスの取り込み・視点の動き・走る速さの手ごたえは、実際に動かして確かめてほしい。
- **1人称の見た目が簡素。** 自分の手・体は見えない。歩くときの揺れが少しあるだけ。村人との衝突は、ない(すり抜ける)。
- **プレイヤーは、警官になれない。** パトロール・逮捕ができない。
- **会話の話題が決まっている。** 自由な文章を打つことはできない。話題は6つ。言葉の種類も、少ない(同じ文がくり返し出る)。
- **会話の言葉は、声や文字の演出がない。** 吹き出しと、会話の画面だけ。
- **CPU どうしの会話は、おしゃべりをしているときだけ。** 道ですれ違ったときの会話・あいさつはない。
- **メニューが長い場所**(コンビニの前など)がある。ページ送りで対応している。
- **時間は、メニューと会話の間、止まる。** CPU が待ってくれる形で、リアルタイムの緊張感は弱い。
- **プレイヤーの自宅の見た目・持ち物はない。** 自宅の中に入って寝るだけ。
- **牧場へは遠い。** 畜産家になったプレイヤーは、歩いて向かう。

# 追加の調整(操作まわりの見直し)

実際に触ってもらった感想をもとに、次の5点を変えた。

## 1. 地図(M キー)

M を押すと、**真上から村全体を見下ろす視点**になる(最初の俯瞰視点と同じ)。このあいだ、プレイヤーは動けない(視点も動かせない)。時間は進むので、CPU の動きは地図で見える。

- 主な場所の名前(広場・コンビニ・交番・会社A/B/C・畑・公園・牧場)を札で出す(`world.landmarks`)。
- **自分の位置・向きを、赤い三角**で出す。自宅は、青い札と光の柱。
- マウスのホイールで拡大・縮小。M か Esc で閉じる。
- 実装は `game/src/map-view.ts`。カメラを真下に向けるだけで、別の画面は持たない。

## 2. 自宅の目印

自宅がどれか分からなかったので、いつでも見える目印を付けた。

- 自宅の上に、**青い光の柱**(脈打つ)と**「🏠 自宅」の札**。札は、遠いほど大きく出して、遠くからも読める。
- 足元には、青い輪。
- 画面の上に、**自宅の方向を示す矢印と距離**(例: `↑ 自宅 28m`。向いている方向に合わせて、矢印が回る)。
- 自宅の中にいるときは、すべて消える。

## 3. パンチ(いつでも)

**左クリック(または F)で、いつでもパンチ**が出せる(0.55 秒の間隔)。

- 画面の右下にこぶしがあり、パンチで前に突き出す。
- 目の前(腕の長さ 2.3 m、正面から約35度まで)にいる村人に当たると、**暴行として扱われる**(見ていた人の感情・通報・巡査による手配は、CPU の暴力と同じ)。
- 当たった相手は、気の短さ・アウトロー度・余裕のなさで、**殴り返して喧嘩になるか、逃げ出す**。巡査は、必ず応じる。
- これに伴い、**メニューの「喧嘩をしかける」は削除**した(喧嘩は、パンチから始まる)。
- 実装: `Society.hit()`(相手の反応)と `PlayerActions.punch()`。

測定(60回殴った): 喧嘩 29回 / 逃走 31回。

## 4. 持ち物のスロット(10個)

持ち物を、**画面下の10個のスロット**に出す。手に入れた順に、空いているスロットへ入り、なくなると空く。数字キー 1〜0 で、スロットを選ぶ。

選んだスロットにものがあるとき:

| キー | 動作 |
| --- | --- |
| R | **食べる**(食料品のみ。満腹が上がり、ゴミが出る) |
| G | **投げつける**。人に当たれば**攻撃**(パンチと同じく、相手は殴り返すか逃げる。パンチより弱い扱い)。当たらなければ、落ちた場所への**ポイ捨て**(巡査に見られれば罰金) |

- メニュー(E)の「〇〇を食べる」は、スロットに移したので削除。
- 時間の速さのキーは、数字キーと重なるため、`[` `]` に変えた(×1・×4・×16・×64)。
- 実装: `Inventory`(`player-actions.ts`)、`PlayerActions.eatSelected()` / `throwSelected()`、`Society.throwLitter()`。

## 5. 会話を、吹き出しだけの簡易なものに

会話の記録(ログ)の画面をやめ、**吹き出し**にした。選べるのは次の3つだけ。

| 選択 | 結果 |
| --- | --- |
| 1 ほめる | 基本は仲が深まる。まれに(約7%)、からかわれたと思われて怒られる。3回ほめると、相手のほうから切り上げる |
| 2 けなす | 相手が怒り、仲が悪くなる。気の短い人は喧嘩になる |
| 3 立ち去る | 会話を終える |

- 自分の言葉は、画面の下の吹き出し。相手の言葉は、相手の頭の上の吹き出し(3秒ほどで消える)。
- 相手の返事のあと(約1秒)に、次の選択ができる。
- 画面に出る選択肢は、会話の最中の小さな枠だけ。
- **不具合の修正**: 会話が終わっても、会話の記録が残り、1 を押しても消えなかった(会話の相手を、終了時に空にしていなかった)。**会話が終わったら、相手と選択肢を、すぐ消す**ようにした。
- CPU どうしの会話(吹き出し)は、そのまま。

## 検証

`player-check` は 34件すべて成功(パンチ・投げる・スロット・新しい会話を追加)。画面では、地図・自宅の柱と札・方向の矢印を、静止画で確認した。

## 試行錯誤

- **地図を開くと、画面が真っ黒になった。** 地図では霧を消したが、空の色を決める処理が霧を直接読んでいて、例外で止まっていた。霧を別の変数に持つようにして直した。
- **最初の地図は、村が小さく、札が重なった。** 高さを下げ(村の輪が画面に大きく入るように)、札を小さくした。自宅の札は、自分の三角と重ならないよう、少し北にずらした。
- **ほめて怒られる確率が高すぎた(18%)。** 普通の会話の半分の確率にして、約7%にした。
- **こぶしが大きすぎた。** サイズを半分にして、位置を遠くした。
- **操作の説明の枠が、スロットに重なった。** 説明を、細い枠にして左下に収めた。

## 残っている課題(追加)

- マウスでのパンチの手ごたえ・当たり判定の広さ(2.3 m・35度)は、実際に遊んで確かめてほしい。
- 地図で、他の村人は見えるが、名前や印はない。
- スロットは、食料品とゴミだけ(10個は、今のところ余る)。道具や贈り物が増えたら使う。
- 投げたものが飛ぶ様子(軌道)はない。前に5 m 先へ落ちたことにしている。
- 会話の言葉の種類が少ない(ほめる・けなすの文が、数種類のくり返し)。

# 効果音(SE)

音のファイルは使わず、**Web Audio でその場で合成**する(`game/src/audio.ts`)。ファイルの配信・読み込みが要らず、サーバーの負担も増えない。ブラウザの決まりで、最初のクリックかキー入力のあとから鳴る。**N キーでオン・オフ**。

| 場面 | 音 |
| --- | --- |
| 歩く・走る | 歩幅(約1.7 m)ごとに、土を踏む足音 |
| パンチ | 空振りは風切り音、当たると鈍い打撃音 |
| 投げる | 風切り音。当たれば打撃音、外れれば、ポイ捨ての音 |
| 食べる・買う | もぐもぐ(3回)・コインの音 |
| ゴミ箱・ポイ捨て・拾う | それぞれ別の音 |
| 家・ビルの出入り | ドアの音 |
| メニュー | 開く・選ぶ・選べない(低いブザー) |
| 知らせ | ふつうは、軽いチャイム。手配・逮捕・勾留・罰金は、サイレン風の3音 |
| 会話 | 吹き出しが出るたびに、声の代わりの小さな音。ほめると明るい3音、けなす・怒られると、低いうなり |
| 睡眠・仕事・説教・喧嘩・勾留 | 行動が始まったときに、それぞれ短い音 |
| 地図 | 開閉の音 |

- 行動の音は、プレイヤーの行動が切り替わった瞬間に鳴らす(`sfxForAction`)。
- 同じ音が、40 ミリ秒以内に重ならないようにした。
- 実際の聞こえ方(音量・音色)は、耳で確かめていない。画面なしの検証で、エラーが出ないことだけ確認した。
- CPU どうしの喧嘩・会話の音は、まだない(プレイヤーの行動だけ)。
