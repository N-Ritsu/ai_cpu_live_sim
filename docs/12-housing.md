# 住まい(アパート・自分の家・大工小屋)と、家の中の床

## 床の修正

家の中に入ると、**床がなく、外の地面とつながって見えた**(壁は両面だったが、床の板がなかった)。会社のビルは、さらに、壁が片面だけで、内側から見ると壁が透けていた。

- 家・アパート・大工小屋・会社のビルに、**床の板**(木・灰色など、建物ごとの色)を付けた。
- 会社のビルとアパートの壁と天井を、**両面**にした(中から見ても、壁が見える)。

## 住まいの全体像

| 種類 | 内容 |
| --- | --- |
| **アパート**(集合住宅) | 村人の、ふつうの住まい。1棟に最大12人(部屋の数)。村人50人なら5棟。全員、最初はアパートに住む |
| **自分の家**(区画に建てる) | お金がたまったら、**大工小屋**で建てられる。小さな小屋・普通の家・立派な家の3種類 |
| **大工小屋** | 家の注文・建て直し・色の変更ができる場所。南の大通りの東側。入口は、広場のほう(北)を向く |

村の外周の「輪」には、内側にアパート、その外側に、家を建てる**区画**(村人の数の約1/4。最低8)が並ぶ。区画は、家が建つまで、何もない空き地(砂利と「空き地」の看板。当たり判定なし)。

## 3種類の家

| 種類 | 値段 | 広さ(屋内) | 外観・中身 |
| --- | --- | --- | --- |
| 小さな小屋 | ¥2,500 | 4 m 四方(歩ける半径 1.6 m) | 四角すいの屋根。ベッドだけ |
| 普通の家 | ¥6,000 | 6 m 四方(歩ける半径 2.6 m) | 切り妻の屋根。ベッドとテーブル・椅子 |
| 立派な家 | ¥15,000 | 9 m × 7.6 m の2階建て(歩ける半径 3.6 m) | 寄せ棟の屋根・煙突・玄関のひさし・2階の窓。ベッド・テーブル・ソファ・本棚・ラグ |

障害物(外から入れない円)の半径は、3.2 / 4.6 / 6.0 m。玄関の前の点は、その外側に取る(家の大きさで、玄関の位置が変わる)。

## 建てる・建て直す・色を変える

- **注文**: 大工小屋の前で E → 「家を建てる・建て直す…」から、種類を選ぶ。代金は、注文のときに払う。大工小屋が開いているのは **8〜17時**。
- **完成まで1日**(ゲーム内の1日 = 5分)。建てている間は、元のアパートに住む。区画には、**土台・柱・材木と「工事中」の看板**が立ち、進み具合に応じて、壁が立ち上がり(0〜60%)、屋根がのる(65%以降)。
- **完成**すると、そこが自分の住まいになる(玄関・青い光の柱・地図の自宅が、移る)。
- **1人1軒**: 同じ人は、2軒目を建てられない。いまと同じ種類・小さな種類にも建て直せない。
- **グレードアップ**: 今より大きな種類を注文すると、**今の家は取り壊し**、同じ区画に、新しい家を建て直す(1日かかる。その間は、アパート)。
- **色を変える**: 完成した家だけ。大工小屋の前の E →「家の色を変える…」で、**壁**(8色: クリーム・白・水色・若草色・ピンク・黄色・灰色・茶色)・**屋根**(8色: 赤茶・紺・緑・黒・オレンジ・灰色・紫・青緑)を、1回 ¥400 で変えられる。

## 大工(職業)

- 定員あり(村人の6%・最低2人。50人なら、最初は2人 + 転職で3人)。給料は、仕事1回(4時間)¥1,100。勤務は 8〜17時。橙色の作業着。
- 仕事は、**建築中の家の前**(なければ、大工小屋の前)で働く。家を建てる速さは、大工の人数にかかわらず、1日。
- 適性: 勤勉・好奇心が強い人。職業の見直しで、会社員から転職してくる人もいる。

## CPU も、家を建てる

CPU も、お金がたまると、大工小屋へ行って注文する(行動 `order_house_1/2/3`)。

- 条件: 持っているお金が「値段 + 貯え(¥2,000。建て直しは ¥3,500)」以上・大工小屋が開いている時間・倹約家(thrift 0.65 以上)ではない・空きの区画がある。
- 買える中で、いちばん大きな家を選びやすい。浪費家ほど、余裕があるほど、建てたがる。
- **プレイヤーのために、区画の1/4(最低2)を、CPU が使わずに残す**(CPU が、区画を使い切って、プレイヤーが建てられなくなるのを防ぐ)。
- 注文の途中でやめたとき(夜になった・ほかの用事ができた)は、払ったお金を返す。
- CPU は、色の変更はしない(建てるときに、壁と屋根の色が、ランダムに決まる)。

## 測定(`npm run housing-check`。29件すべて成功)

- アパート 5棟に、11・10・10・10・10人。大工 2人。
- 3人(お金 ¥4,000 / ¥8,500 / ¥20,000)が、それぞれ小さな小屋・普通の家・立派な家を注文。注文から**ちょうど 1.00 日**で完成し、住まいになる。
- 同じ人は2軒目を建てられない。建て直しは、同じ区画で行い、古い家は取り壊される。
- プレイヤーが、大工小屋で ¥2,500 払って小さな小屋を注文 → 1日後に完成 → 壁の色を ¥400 で変更。
- 自然に9日過ごすと、CPU が **8軒**を注文(完成 4軒)。大工は、1日約 6.7 時間働く。

経済への影響(村人50人・9日分): 収入 ¥879/日・支出 ¥693/日。お金がない人(< ¥120)の割合は 4.3%。職業ごとの収入の序列は、変わらない(定員のある職業 > 会社員)。

## 試行錯誤

- **注文のお金が消えた。** 注文の途中で、行動がやめられると(夜になった・ほかの用事)、払った代金が戻らなかった(行動の「着いたとき」に払う仕組みのため)。やめたときに返すようにした。
- **お金の多い人が、安い家を選んだ。** 余りのお金で点を付けていたため、安い家が高く評価された。**種類が大きいほど点が高い**ようにして、買える中で最大の家を選ぶようにした。
- **CPU が区画を使い切った。** お金のある人は、早く建てる。1割を超える人が、9日で13区画を使い切りそうだった。**倹約家は建てない・貯えを増やす・プレイヤー用に区画を残す**ようにした。
- アパート・区画の導入で、村が少し大きくなった(村の半径 約 48 → 58 m)。配置の検査では、重なり 0件・目的地が建物の中に入る点 0件。

## 残っている課題

- CPU は、色を変えない。家を取り壊しても、色は引き継ぐだけ。
- 家の中の家具は、固定(動かせない・増やせない)。
- 家の前に、名札・表札はない。他の人の家は、見た目だけでは、誰のものか分からない(家の中の人が見えるわけでもない)。
- アパートの中は、1つの広い部屋(12人分のベッドの位置は、見えないところにある)。他の人の部屋とは、区別されない。
- 大工が働いても、建築の速さは、変わらない(1日固定)。
- 売却・引っ越し・取り壊しだけの手続きは、ない。
- 実際に歩いて、家の中の広さの感覚・外観は、静止画でしか確かめていない。
