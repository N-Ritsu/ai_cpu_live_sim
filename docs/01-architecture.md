# 全体の作り(案)

まだ案の段階。固まったものは [decisions.md](decisions.md) に移す。

## 方針

- **1人で遊ぶゲームなので、計算は全部プレイヤーのブラウザの中で行う。** 計算用のサーバーは持たない。村人が50人でも500人でも、サーバーの負荷は変わらない。
- 重くなるのは、遊ぶ人の端末(CPUとGPU)。性能の工夫はそちらに集中する。
- セーブは、まずブラウザの中(IndexedDB など)に置く。クラウドに置くかどうかは必要になってから決める。

## 層の分け方

```
ゲーム本体(描画・操作・世界)
   │  知覚(見えるもの・時刻・近くの人)を渡す
   ▼
ai_cpu(頭脳)  ← ゲームを知らない。純粋な計算だけ
   │  意図(何をしたいか)を返す
   ▼
ゲーム本体が、歩く・話すなどの動きにする
```

`ai_cpu` は描画も世界の仕組みも知らない。ゲーム側とのやりとりは「知覚」と「意図」の2つの形だけ。

## 性能の考え方(村人50人・オブジェクト多数)

| 場所 | 工夫 |
| --- | --- |
| 描画 | 同じ形はまとめて描く(インスタンシング)。遠くは簡易モデル。描画の呼び出し回数を数百以内に |
| アニメーション | 50人の骨アニメを全部まともに回さない。遠くは省く、または頂点アニメーションのテクスチャ方式 |
| AI | 全員を毎フレーム考えさせない。画面に近い村人ほど頻繁に、遠い村人は粗く(`ai_cpu` のスケジューラ)。重ければ Web Worker に出す |
| 容量 | 3Dモデルは圧縮(meshopt・KTX2 など)して軽く |

## 候補の技術(未決定)
