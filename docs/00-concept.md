# コンセプト

## ひとことで

村人CPUを本物の人間のように動かし、プレイヤー自身もその村の一員として暮らす3Dゲーム。

## 決まっていること

- 3D。村人は50人規模、周りに置くオブジェクトも多数。
- 村人CPUは「ゲームの都合で動く駒」ではなく、欲求・性格・記憶をもとに自分で行動を決める。
- プレイヤーは村人の一員として村に入る(特別な視点の神様ではない)。
- 別のゲーム(ふるさと百代記)とは**無関係の、1から作る新作**。
- 他のプレイヤーとの交流・通信は**今は考えない**(1人で遊ぶゲーム)。
- 村人CPUの頭脳(行動の決め方・内部パラメータ)は `ai_cpu/` にまとめ、他のゲームでも使い回せるようにする。
