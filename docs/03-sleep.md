# 睡眠の個性

村人ごとに睡眠のしかたが違うようにする。「1つずつ整理する」の1番目。

## 欲しかった個性

早起き / 夜更かし / ショートスリーパー / ロングスリーパー / 昼寝好き

## 設計

3つの特性(0〜1)の組み合わせで表す。1人が複数を持てる(例: 夜更かし かつ ロングスリーパー)。

| 特性 | 0 | 1 | 効くこと |
| --- | --- | --- | --- |
| `chronotype`(夜型度) | 早起き | 夜更かし | 寝たくなる時刻 = 22時 + (値 − 0.5) × 4時間 → 20時〜24時 |
| `sleepNeed`(睡眠欲) | ショートスリーパー | ロングスリーパー | 夜の睡眠時間 = 9時間 × (0.65 + 0.55 × 値) → 約5.9〜10.8時間。眠気のたまる速さも 0.8〜1.2 倍 |
| `napLover`(昼寝好き) | 昼寝しない | 昼寝好き | 昼下がり(12〜16時)に昼寝を好む。1日に1回まで |

ラベルは、値が 0.25 未満 / 0.75 超のときに付く(例: `chronotype < 0.25` で「早起き」)。

### 特性の割合(釣り鐘型)

珍しい特徴は、珍しくする。特性値は釣り鐘型(正規分布)で決め、ほとんどの人は平均付近(= 「ふつう」)に集まる。

| 特徴 | 条件 | 分布(平均 / 標準偏差) | 割合 |
| --- | --- | --- | --- |
| 早起き | `chronotype` < 0.25 | 0.5 / 0.2 | 約11% |
| 夜更かし | `chronotype` > 0.75 | 0.5 / 0.2 | 約11% |
| ショートスリーパー | `sleepNeed` < 0.25 | 0.52 / 0.15 | 約4% |
| ロングスリーパー | `sleepNeed` > 0.75 | 0.52 / 0.15 | 約6% |
| 昼寝好き | `napLover` > 0.75 | 0.45 / 0.24 | 約11%(昼寝をほとんどしない人は約20%) |

- 1人ずつ乱数で引くと、人数が少ないときに割合がぶれる(0人だったり、多すぎたり)。そこで、分布を人数分に等分した位置の値を並べ、順番だけを乱数で入れ替えて割り当てる(`ai_cpu` の `stratifiedNormal`)。村人50人なら、早起き5人・夜更かし5人・ショート2人・ロング3人・昼寝好き5人。人数を変えても、割合は保たれる。
- 以前は 0〜1 の一様乱数で決めていたので、各特徴が約25%(4人に1人)に付いていた。現実より、かなり多かった。
- 割合は、睡眠の研究・調査の数字をそのまま使ったものではなく、「珍しい特徴は1〜2割以下」にするための、この世界の設定。変えたいときは `game/src/sleep.ts` の `SLEEP_TRAIT_DISTRIBUTION`。

### 夜の睡眠(`sleep`)

- その人の「寝る時間帯」(就寝時刻〜+睡眠時間)に入ると、眠気(元気の低さ)に応じて強く選ばれる。
- 時間帯の外では、疲れ切ったとき(元気 0.2 未満)だけ寝られる。
- 時間帯が終わる直前(残り1.5時間以内)からは、新しく寝始めない。
- 寝始めたら、時間帯が過ぎても最後まで寝る。ひどい空腹など、よほどのことがなければ途中で起きない(`inertia` 0.8)。
- 寝る時間帯の間は、おしゃべり・畑仕事・散歩ができない(食事だけはできる)。

### 昼寝(`nap`)

- 起きている時間帯の昼間に、元気が 0.95 未満なら選べる。所要時間は夜の1/3(3時間分)、回復量は 0.35。
- `napLover` が高いほど選びやすい。12〜16時はさらに加点。
- クールダウン 0.7日: 1日に1回まで。

### ai_cpu に足した、他の個性にも使える仕組み

睡眠だけのコードを入れず、汎用の仕組みにした([ai_cpu/design.md](ai_cpu/design.md))。

| 仕組み | 睡眠での使い方 |
| --- | --- |
| `Personality.needDecayScale` | 睡眠欲が高い人ほど、眠気がたまりやすい |
| `Personality.durationScale` | 睡眠欲に応じて、睡眠行動の長さを変える |
| `ActionSpec.cooldownSec` | 昼寝を1日1回に |
| `ActionSpec.inertia` | 寝たら起きにくく |
| `AgentView.currentActionId` | 寝ている最中は、時間帯が終わっても「寝続けられる」 |

睡眠の時間帯の計算・ラベルは、この世界のルールなのでゲーム側(`game/src/sleep.ts`)に置いた。

## 確認 (2026-11-22)

描画なしで村人50人の3日分を動かし、個性ごとに集計した(`npm run sleep-check`)。「就寝」は寝ると決めた時刻(家まで歩く時間は含めない)。1日を5分(300秒)にし、特性を釣り鐘型の割合にした後の結果。

| グループ | 人数(割合) | 就寝 | 起床 | 睡眠時間 | 昼寝/日 |
| --- | --- | --- | --- | --- | --- |
| 早起き | 5(10%) | 20:38 | 05:30 | 8.9h | 0.27 |
| ふつう(時刻) | 40(80%) | 22:02 | 07:06 | 9.1h | 0.42 |
| 夜更かし | 5(10%) | 23:24 | 08:42 | 9.3h | 0.40 |
| ショートスリーパー | 2(4%) | 22:17 | 05:32 | 7.2h | 0.00 |
| ふつう(睡眠) | 45(90%) | 21:58 | 07:01 | 9.0h | 0.45 |
| ロングスリーパー | 3(6%) | 22:34 | 09:03 | 10.5h | 0.00 |
| 昼寝好き(`napLover` > 0.75) | 5(10%) | 22:24 | 07:31 | 9.1h | 1.00 |
| 昼寝しない人(`napLover` < 0.25) | 10(20%) | 21:52 | 06:59 | 9.1h | 0.00 |

- 就寝・起床の順番(早起き → ふつう → 夜更かし)、睡眠時間の順番(ショート < ふつう < ロング)、昼寝好きは毎日昼寝・昼寝しない人は昼寝ゼロ、は設計どおり。
- 設定の就寝時刻と実際に寝始めた時刻の差は、平均 +0.03 時間。
- 「睡眠時間」は、寝ると決めてから起きるまで(歩く時間を含む)なので、設定の睡眠時間より約0.5〜1時間長く出る。
- 昼寝の列の「ふつう」が約0.4回/日なのは、昼寝好きでも昼寝しない人でもない中間の人が、日によって昼寝するため。
- ショート・ロングスリーパーは人数が2〜3人なので、数字はぶれる。

## 試行錯誤

1. **最初は睡眠が設定の半分以下(約3時間)だった。** 寝ている間に眠気が回復する → 睡眠の点数が下がる → 空腹などの他の行動に負けて起きる、という流れだった。`inertia`(行動ごとの続けやすさ)を足し、睡眠だけ 0.8 にして解決した。
2. **就寝が設定より約2.7時間遅れた。** 測り方が「家に着いた時刻」だったため、歩く時間(この村の広さと1日の短さだと約2時間分)が入っていた。「寝ると決めた時刻」で測るようにし、あわせて行動の見直し間隔を 5秒 → 2秒(ゲーム内の約12分)にして、約0.7時間になった。
3. **夜更かしのロングスリーパーが、朝9時から10時間寝ていた。** 開始時刻(9時)がちょうど寝る時間帯の終わりぎわで、そこから「まる1回分」寝始めていた。時間帯の終わりぎわから新しく寝始めない、にした。

## 残っている課題

- ~~昼寝・夜の睡眠が、玄関の前で横になる。~~ → 家に入って寝るようにした([05-crime-and-police.md](05-crime-and-police.md))。

- ~~1日が短い(240秒)せいで、歩く時間が粗く効く。~~ → 1日を1200秒にして解決した([04-economy.md](04-economy.md))。
- **起こされる・眠れない夜**: 病気、心配事、騒音、満月など、睡眠が乱れる要因はまだない。
- **日による揺れ**: 就寝時刻は毎日ほぼ同じ。曜日・出来事・気分で、日ごとに揺れてほしい。
- **睡眠中の見た目**: 横になるだけ。寝息・「Zzz」などの表現はない。
- **光との関係**: 暗くなると眠くなる、朝日で目が覚める、は入っていない(時刻だけで決めている)。
- **プレイヤーとの関わり**: 起こす・寝ている村人を訪ねる、など。

## あとから変えたこと

- 特性値を、一様乱数 → 釣り鐘型の割合(上の「特性の割合」)にした。理由: 珍しい特徴(昼寝好きなど)を持つ人が、4人に1人と多すぎたため。
- 1日を 1200秒 → 300秒(5分)にした。
- 1日を240秒 → 1200秒にした(のち300秒)。睡眠の長さ(9時間・昼寝2時間)は「ゲーム内の時間」で書くようにしたので、日の長さを変えても、睡眠時間(時間単位)は同じ。昼寝は3時間 → 2時間にした。
- 昼寝は、昼下がり(12〜16時)以外は、よほど疲れていなければしないようにした(1日を長くすると、空き時間の埋め草として昼寝が増えたため)。
