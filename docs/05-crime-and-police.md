# マナー・犯罪・警察

「1つずつ整理する」の3番目。村人に「悪い面」(マナー違反・犯罪)を持たせ、それを取り締まる警察を置いた。あわせて、村人が家の中で寝るようにした。

**「悪感情」の解釈**: 依頼文の「悪感情」を、マナー違反や犯罪といった、反社会的な面と解釈した。怒り・憎しみなどの感情そのもの(気分・人間関係)は、まだ入っていない(下の課題)。

## 1. 家の中で寝る

- 寝る・昼寝のとき、村人は玄関まで歩き、家に入り、家の中のベッド(同居の2人で左右に分ける)で寝る。起きたら、玄関から出る。
- 玄関と反対側から来たときは、家をぐるっと回って玄関へ向かう。
- 家の中にいる村人は、壁の中なので描かない(クリックでは選べない。選んでいる場合は、家の屋根の上に大きな輪が出る)。
- 確認: 寝ている村人の100%が、家の中にいた(`npm run crime-check`)。

## 2. 性格(素行)

3つの特性(0〜1)で、依頼の4タイプを表す。

| タイプ | 表し方 | 割合 |
| --- | --- | --- |
| マナーにうるさい | `manners` > 0.75 | 約11% |
| マナーを守らない | `manners` < 0.25 | 約11% |
| 正義感が強い | `justice` > 0.75 | 約11% |
| アウトロー | `outlaw` > 0.75 | 約5% |

- 珍しい特徴は珍しくする方針([03-sleep.md](03-sleep.md))。`manners`・`justice` は釣り鐘型。`outlaw` は、釣り鐘型の値を2乗して、ほとんどの人は低く、極端な人は少なくした(中央値 約0.25)。人数分の分位点を並べて割り当てるので、50人なら、マナーにうるさい5人・守らない5人・正義感4人・アウトロー2人。
- アウトローは、正義感が低く、マナーも守らない傾向にした(`coupleCharacter`)。別々に決めると、「アウトローで正義感も強い」という矛盾した人が出る。
- 自分で足した特性はない(依頼の4タイプを、この3軸で表せたため)。

## 3. マナーの行動

食事のあとに「ゴミ」が出る。ゴミをどうするかで、マナーが表れる。

| 行動 | 選びやすい人 | 内容 |
| --- | --- | --- |
| ゴミを捨てる(`dispose`) | マナーを守る人 | ゴミ箱(コンビニの前・広場)へ歩いて捨てる |
| ポイ捨て(`litter`) | マナーを守らない人 | その場にゴミを落とす。地面にゴミが残る |
| ゴミ拾い(`pickup_litter`) | マナーにうるさい人・正義感が強い人 | 落ちているゴミを拾いに行く |

- ポイ捨てを巡査が見ていた(12m以内)ときは、その場で(即時に)罰金 ¥100。軽い違反なので、手配はしない。巡査に見られなければ、罰金も手配も逮捕もない([07-good-deeds.md](07-good-deeds.md)で確認)。

## 4. 犯罪と、手を出す閾値

犯罪は2つ。

- **万引き**(`steal_*`): コンビニで、お金を払わずに食料品を取る。追い詰められ度は、空腹の度合い(お金が最安の食料品より少ないときはそのまま、お金があるときは6割)。
- **すり**(`pickpocket`): 近く(40m以内)の村人から、お金を盗む(¥150〜400)。追い詰められ度は、お金の少なさ(¥400 以上あれば0)。

**追い詰められ度が、その人の「犯罪に手を出す閾値」を超えると、犯罪が選べるようになる。** 閾値は人によって変わる。

```
閾値 = 0.8 + 0.5 × (正義感 − 0.5) + 0.3 × (マナー − 0.5) − 0.6 × (アウトロー − 0.25) + 反省
追い詰められ度 = (欲求の不足) + 0.25 × アウトロー度
```

- 正義感が強い・マナーにうるさいほど閾値が高く(手を出さない)、アウトローほど低い(すぐ手を出す)。巡査のように正義感が強い人は、閾値が 1 を超え、どんなに追い詰められても手を出さない。
- **反省**: 逮捕された回数 × 0.1(最大 +0.5)だけ、閾値が上がる。
- 警察がコンビニの近く(15m以内)にいると、万引きをためらう(アウトローは、あまり気にしない)。巡査が勤務中だと、すりもためらう。
- 空腹を満たす行動としては、買うより万引きのほうが、値段の分だけ得になる。お金があっても、アウトローは万引きを選びやすい。

## 5. 警察

- **巡査は2人**。正義感が強く、アウトローでなく、マナーを守る人を、正義感の高い順に選ぶ(巡査の特性: 正義感 0.75 / 0.80)。紺の制服と帽子。
- **交番**(広場の南)を建てた。巡査の拠点で、逮捕した人を連れてくる。
- **パトロール**: 勤務時間のあいだ、決まった経路(広場・コンビニ・交番・村の外周)を歩く。1回ごとに給料が入る(のち ¥60 に変更。[06-feelings.md](06-feelings.md))。勤務は、巡査Aが 6〜17時、Bが 11〜22時。勤務外は、ふつうの村人と同じように暮らす(食事・睡眠・おしゃべり)。畑仕事はしない。
- **発覚**: 犯罪は、次のどれかで「手配」になる。
  - 12m以内にいる巡査が目撃する。
  - 10m以内にいる、正義感が強い人などが目撃し、歩いて交番へ通報しに行く(のち変更。[06-feelings.md](06-feelings.md))。
  - 万引きは、防犯カメラに半分の確率で映る。
  - どれでもなければ、気づかれずに終わる。
- **逮捕**: 手配された人に、空いている巡査(起きていて、ほかの逮捕の最中でない人)を、近い順に割り当てる。巡査は、犯人を追いかけ(家の中にいれば、玄関まで)、追いつくと逮捕する。
- **勾留**: 逮捕された人は、交番へ連れていかれ、3時間(ゲーム内)留め置かれる。罰金は最大 ¥300(ただし所持金の半分まで)。逮捕歴が1つ増える。
- 手配は1.5日で時効。

### ai_cpu に足した仕組み

- **出来事の取り出し**(`Agent.drainEvents()`): 行動の「始めた・やり終えた・途中でやめた」を、ゲームが受け取れる。ゴミが地面に残る、盗んだお金が移る、逮捕が成立する、といった世界への反映は、この出来事をきっかけに、ゲーム側(`game/src/society.ts`)が行う。ai_cpu は、お金・犯罪・警察を知らない。
- 逮捕・勾留・巡査の指示は、ai_cpu の持ち物(`assignment`・`detained` など)を、フラグとして使っている。

## 確認 (2026-11-22)

村人50人の9日分(1日目は除く)を描画なしで動かして集計した(`npm run crime-check`)。

**素行ごとの行動(1人1日あたり)**

| グループ | 人数 | ゴミ捨て | ポイ捨て | ゴミ拾い | 万引き | すり |
| --- | --- | --- | --- | --- | --- | --- |
| アウトロー | 2 | 2.11 | 0.17 | 0.00 | 0.94 | 0.00 |
| マナーを守らない | 5 | 0.16 | 0.91 | 0.00 | 0.13 | 0.02 |
| マナーにうるさい | 3 | 3.48 | 0.00 | 1.19 | 0.00 | 0.00 |
| 正義感が強い | 3 | 1.19 | 0.04 | 0.00 | 0.15 | 0.00 |
| ふつう | 35 | 1.82 | 0.06 | 0.10 | 0.07 | 0.01 |

- マナーを守らない人はポイ捨てをし(ゴミ捨てはほとんどしない)、マナーにうるさい人はゴミを捨て、ゴミを拾う。
- 万引きの中心は、アウトローと、追い詰められた人。正義感が強い人でも、閾値を超えるほど追い詰められると、まれに(0.15回/日)万引きをする。
- ※「正義感が強い」と「マナーにうるさい」「アウトロー」は、1人が複数に当てはまることがある(行は重ならないように集計しているわけではない)。

**治安(村全体)**

| 項目 | 結果 |
| --- | --- |
| 犯罪 | 万引き 66件・すり 5件 → 1日あたり約 7.9件 |
| 発覚 | 巡査が目撃 21 / 通報 43 / 防犯カメラ 1 / 気づかれず 6 |
| 逮捕 | 46件。手配から逮捕までは平均 1.6時間(ゲーム内)、最長 9.5時間 |
| ポイ捨て・ゴミ | ポイ捨て 68件(巡査による罰金 28件)・ゴミ拾い 68件・ゴミ捨て 806件。地面のゴミは平均 0.5個 |
| 巡査の時間の使い方 | パトロール 36〜40% / 睡眠 33〜34% / 逮捕に向かう 5〜6% / おしゃべり 10〜15% |

- 家の中で寝る: 寝ている村人の100%が、家の中。
- 村人200人でも動く(1日あたり約45件の犯罪)。逮捕までは平均 6.7時間に伸びる(巡査が2人のままのため)。
- 村人300人の処理は、1ステップ(1/10秒)あたり約 1.4 ms。

## 試行錯誤

1. **最初は、犯罪が1日あたり約52件**あった。ふつうの人まで万引きをし、同じ人が何度も逮捕されていた。原因は、アウトロー度の分布が平均 0.35 と高く、3分の1の人が「ややアウトロー」になっていたこと。アウトロー度を「釣り鐘型の値の2乗」(ほとんどの人は低い)に変えた。
2. **反省がなく、アウトローは1日3回逮捕された。** 前科の数に応じて、閾値が上がるようにした。
3. **罰金 ¥600 で所持金が0になり、お金がない → すり・万引き → 逮捕 → 罰金、の悪循環**が起きた。罰金を ¥300 に下げ、犯罪に手を出す基準も少し上げた(0.7 → 0.8)。→ 犯罪は1日あたり約8件に。
4. 手配から逮捕までの時間が、最初から短かった(平均 1.5時間)。巡査は、手配された人に近い順に向かい、犯人も普通に暮らしているため、追いつきやすい。**犯人が逃げる行動はまだない**(下の課題)。

## 残っている課題

- ~~逃走がない。~~ → 追い詰められた犯人が、投降・逃走・反撃をするようにした([06-feelings.md](06-feelings.md))。
- **巡査が2人のまま。** 人口に比例して増えるわけではなく、200人だと追いつかない。
- **店員・店の中がない。** 万引きは、店員に見つかることがなく、防犯カメラ(50%の抽選)だけ。
- ~~感情がない。~~ → 対人感情・説教・喧嘩を足した([06-feelings.md](06-feelings.md))。復讐・恨みの持続・噂は、まだない。
- **犯罪の種類が少ない。** 万引き・すりだけ。欲求のうち、空腹とお金にしか結びついていない(睡眠・社交・働きの欲求が満たされないとき、の悪さは未実装)。
- **マナーの種類が少ない。** ゴミ関係だけ。順番待ち・騒音・あいさつなどは未実装。
- **裁判・刑罰が単純。** 勾留3時間と罰金だけ。
- **プレイヤーはまだ関われない。** 犯罪を目撃して通報する、盗まれる、罰金を取られる、などはない。
