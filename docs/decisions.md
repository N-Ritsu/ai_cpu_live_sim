## 2026-11-22 (3D試作)

- **3D は Three.js + Vite + TypeScript。** 置き場所は `game/`。`ai_cpu` は `game/src/brain.ts`(この世界の定義)と `villagers.ts` からだけ使う。詳しくは [02-prototype.md](02-prototype.md)。
- **村人は `InstancedMesh`(体・頭・鼻の3つ)で描く。** 50人でも描画呼び出しは3回。
- **ai_cpu に「選ぶ」と「始める」の区別を足した**(`requiresEngagement` と `agent.engage()`)。理由: 場所へ歩く時間の間に行動が終わってしまい、村人が歩きっぱなしになったため。詳細は [ai_cpu/design.md](ai_cpu/design.md)。
- **欲求の減る速さは、1日(240秒)で収まるように遅くした**(満腹 0.0045/秒など)。

## 2026-11-22

- **新作として1から作る。** 別のゲーム(ふるさと百代記)とは無関係。`services.md` はそのゲームで使ったサービスの参考資料にすぎず、このゲームの構成を縛らない。
- **1人で遊ぶ。他のプレイヤーとの交流は今は考えない。** → 計算は全部ブラウザの中。計算用のサーバーは持たない。
- **GitHub には文書だけ送る。プログラムは送らない。** `.gitignore` で、`README.md` と `docs/` 以外を除外。送る前の確認は、毎回はしない(Claude への指示)。
- **村人の頭脳は `ai_cpu/` に分ける。** ゲーム・描画に依存せず、他のゲームでも使えるようにする。
- **`ai_cpu` は TypeScript・外部ライブラリなし・種つき乱数・状態は保存可能な形。** 理由: 再現できるテスト、セーブ、Node とブラウザの両対応のため。
- **行動の決め方は、まずユーティリティAI(点数方式)から始める。** 理由: 欲求・性格・状況を足し算で混ぜられ、調整しやすい。行き詰まったら他の方式との組み合わせを考える。
- **メインの枝の名前は `main`。**
