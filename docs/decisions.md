## 2026-11-22 (マナー・犯罪・警察・家で寝る)

- **家の中で寝る。** 玄関から入り、屋内のベッドで寝て、玄関から出る。家の中の村人は描かない。
- **素行の性格は3軸**(マナー意識・正義感・アウトロー度)で、依頼の4タイプ(マナーにうるさい・守らない・正義感が強い・アウトロー)を表す。珍しい特徴は珍しくする(アウトローは約5%)。詳細は [05-crime-and-police.md](05-crime-and-police.md)。
- **「悪感情」は、マナー違反と犯罪(反社会的な面)と解釈した。** 怒り・恨みなどの感情そのものは、まだ入れていない。
- **マナーの行動はゴミ。** 食事でゴミが出る → 捨てる/ポイ捨て/拾う、でマナーが表れる。
- **犯罪は万引き・すり。** 欲求(空腹・お金)が満たされず追い詰められるほど起こしやすい。手を出す閾値は、正義感・マナー・アウトロー度・前科(反省)で変わる。
- **警察は巡査2人**(正義感の高い人を選ぶ)。交番、パトロール、目撃・通報・防犯カメラによる手配、追跡、逮捕、勾留(3時間・罰金 ¥300)。
- **ai_cpu に、行動の出来事の取り出し(`drainEvents`)を足した。** 世界への反映(ゴミ・盗み・逮捕)はゲーム側。ai_cpu は、犯罪・警察を知らない。

## 2026-11-22 (特性の割合・1日5分)

- **珍しい特徴は、珍しくする。** 睡眠の特性(夜型度・睡眠欲・昼寝好き)を、一様乱数 → 釣り鐘型で決める。極端な人(早起き・夜更かし・昼寝好きなど)は1割前後以下、ショートスリーパーは約4%。詳細は [03-sleep.md](03-sleep.md)。
- **特性は、人数分の分位点を並べて割り当てる**(`ai_cpu` の `stratifiedNormal`)。理由: 1人ずつ引くと、人数が少ないときに割合がぶれるため。
- **1日を 1200秒 → 300秒(等速で5分)にした。** 村人が歩く速さには、`WALK_SPEED_SCALE`(平方根で1200秒に対する倍率。300秒で2倍)をかける。

## 2026-11-22 (コンビニ・お金・ポーズ)

- **コンビニで食料品5種類を売り、村人は買って食べる。畑仕事の賃金でお金が増える。** 酒場(無料で食事)はなくした。詳細は [04-economy.md](04-economy.md)。
- **ai_cpu に「持ち物」(`resources`)と、行動の支払い・獲得(`costs` / `gains`)を足した。** お金も食料品も、ai_cpu から見ると持ち物の1項目。お金の意味はゲーム側。
- **1日を240秒 → 1200秒(等速で20分)にした(のち300秒)。** 理由: 村の移動に1日の2〜3時間分かかり、1日の行動が収まらなかった。行動の長さ・欲求の減る速さは「ゲーム内の時間」(時間・1日あたり)で書き、1日の長さは `game/src/time.ts` の `DAY_SEC` 1か所で変えられる。
- **ポーズは Space か P。** 世界の時間(村人・昼夜)と、プレイヤーの移動を止める。視点の操作と、村人の中身の確認はできる。時間の速さは ×1・×4・×16・×64(キー 1〜4)。
- **プレイヤーにも所持金(¥1,000)があり、コンビニで買う・畑で働くことができる。** 空腹などの欲求はまだない。

## 2026-11-22 (睡眠の個性)

- **睡眠の個性は3つの特性で表す**: 夜型度(早起き↔夜更かし)、睡眠欲(ショート↔ロングスリーパー)、昼寝好き。1人が複数を持てる。詳細は [03-sleep.md](03-sleep.md)。
- **個性の仕組みは ai_cpu に汎用で足し、睡眠のルールはゲーム側に置く。** 足したもの: `needDecayScale`・`durationScale`・`cooldownSec`・`inertia`・`AgentView` の拡張。理由: 睡眠のコードを ai_cpu に入れると、他のゲームで使えなくなるため。
- **寝る時間帯が終わる直前からは、新しく寝始めない。**
- 今後は「1つずつ整理する」方針で、テーマごとに `docs/0N-テーマ.md` を作る。

## 2026-11-22 (3D試作)

- **3D は Three.js + Vite + TypeScript。** 置き場所は `game/`。`ai_cpu` は `game/src/brain.ts`(この世界の定義)と `villagers.ts` からだけ使う。詳しくは [02-prototype.md](02-prototype.md)。
- **村人は `InstancedMesh`(体・頭・鼻の3つ)で描く。** 50人でも描画呼び出しは3回。
- **ai_cpu に「選ぶ」と「始める」の区別を足した**(`requiresEngagement` と `agent.engage()`)。理由: 場所へ歩く時間の間に行動が終わってしまい、村人が歩きっぱなしになったため。詳細は [ai_cpu/design.md](ai_cpu/design.md)。
- **欲求の減る速さは、1日(240秒)で収まるように遅くした**(満腹 0.0045/秒など)。
