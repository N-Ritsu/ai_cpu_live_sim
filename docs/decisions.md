## 2026-11-22 (配置の見直し・プレイヤー・対話)

- **村の配置を、道路と区画で整理した**: 北にオフィス街、東にコンビニ、西に交番、広場を中心に、南西に畑・南東に公園、外周に住宅、輪のすぐ外に牧場。建物の入口は、道に向けてそろえた。重なりを確かめるツール(`layout-check`)を作った。詳細は [09-layout-player-talk.md](09-layout-player-talk.md)。
- **プレイヤーは、CPU と同じ「村人」の1人にした。** 欲求・持ち物・職業・感情を持ち、行動は ai_cpu の同じ行動を、自分で始める。だから、目撃・通報・逮捕・感情が、CPU と同じ処理で反映される。
- **視点は、1人称。** E で、場所・目の前の村人に応じた「行動メニュー」を開き、CPU がとれる行動を全部とれる(警官だけの行動は除く)。
- **ai_cpu に、手動モードを足した**(`setManual` / `start` / `cancel` / `currentIntent`)。人間が選んだ行動には、`isAvailable` を当てはめない。
- **メニューと会話の間は、世界の時間を止める。** 睡眠・仕事などの長い行動の最中は、時間を自動で速く進める。
- **対話を足した**: CPU どうし(吹き出し)・プレイヤーと村人(話題を選ぶ)。基本は仲が深まり、たまに(約8%)言い争いになる。短気な2人の言い争いは、喧嘩に発展することがある。
- **配置を変えたので、給料を引き上げた**(通勤が長くなり、収入が足りなくなったため)。

## 2026-11-22 (職業)

- **職業を増やした**: 会社員(定員なし・ビル3棟に出勤)・畜産家(牧場と家畜小屋)・店員(コンビニ)・フリーター(畑の日雇い)。警官と合わせて5つ。詳細は [08-jobs.md](08-jobs.md)。
- **全員が1つの職業に就き、転職しない限り変わらない。** 転職は、1日に1回の見直しで、空きのある、より高給で適性のある職業へ。適性が低いと、辞めて会社員になることもある。
- **会社員以外は定員あり。定員がある職業は高給**(会社員の 1.3〜2.2倍)。警官・フリーターも含めた(「警官含め、定員がある職業は高給」を、文字どおりに受け取った)。
- **旧「畑仕事」は、フリーターの日雇いにした。** 会社員は、ビルの中で働く(中に入ると見えない)。
- **牧場と動物(牛5・羊7・鶏9)を足した。** 動物は、歩き回るだけ。餌は、畜産家が世話をすると増える。
- **店員が店番をしていると、万引きは見つかりやすく、ためらう人も増える。**
- **建物の出入りを、住宅だけでなく会社のビルにも使えるように一般化した。** 玄関まで来れば、中の人も逮捕できる。

## 2026-11-22 (良い行動・ばれ方)

- **良い行動**: ゴミ拾い(強化)・お金に困っている人への寄付・食料品の贈り物・友達との食料品の交換。心身が充足している人(欲求が満たされ、平静な人)と、**正義感が強い人**がしやすい。詳細は [07-good-deeds.md](07-good-deeds.md)。
- **贈り物・交換は、仲の良い人どうしで特に起きる**(友達へのプレゼント、友達どうしの交換。友達でなければ交換しない)。
- **罰金は、巡査に見られた瞬間に、即時に引かれる。見られなければ、罰金も手配も逮捕もない。** 確認ツールで、数字が食い違わないかを見る形にした。
- **手配されていない人は、逮捕しない**(巡査と犯人の喧嘩で、手配なしで逮捕していた不具合を直した)。
- **行動を選ぶ時点で、追う相手を決める**(説教・贈り物・喧嘩・逮捕が、静かに失敗していた不具合を直した)。
- **感情が薄れる半減期は4日**(2日 → 4日。友達が残りやすいように)。

## 2026-11-22 (対人感情・説教・喧嘩・追い詰められた犯人)

- **警察の収入**: パトロール1回 ¥60(収入の中心)+ 逮捕成功の手当 ¥100。実測で、1日あたり約 ¥800〜940(畑仕事と同程度)。前は ¥20 で、約 ¥130〜220 しかなかった。
- **対人感情**(-1〜+1)を足した。他人の行動を見た人が、性格に応じて感情を変える。マナー・犯罪・暴力 → 悪意、マナーの良い行動・逮捕 → 好意。**アウトローは逆向き**(マナーの悪い人・犯罪者に好意、警察に悪意)。詳細は [06-feelings.md](06-feelings.md)。
- **説教・通報は、実際に歩いて行く行動にした。** 悪事を見た正義感の強い人・マナーにうるさい人が説教しに行く。犯罪は、歩いて交番へ通報して、はじめて手配になる(以前は、見た瞬間に自動で通報)。
- **説教された人は、性格・精神状態・相手への感情で、謝る・無視する・逆上して喧嘩になる。** 喧嘩に負けるとけがをして休む。
- **精神状態を、新しい欲求「平静」で表す。** 余裕のなさ(平静の低さ + 空腹・疲れ)が、逆上・反撃・犯罪に効く。
- **追い詰められた(巡査が7m以内に来た)犯人は、投降・逃走・反撃のどれかをする。** 性格と精神状態で確率が変わる。
- **新しい性格「短気」(キレやすさ)を足した**(自分で考えた特性)。
- **ai_cpu に、対人感情(`relations`)・欲求の外部調整(`adjustNeed`)・性格の参照を足した。** 感情の変わり方は、ゲーム側。

## 2026-11-22 (マナー・犯罪・警察・家で寝る)

- **家の中で寝る。** 玄関から入り、屋内のベッドで寝て、玄関から出る。家の中の村人は描かない。
- **素行の性格は3軸**(マナー意識・正義感・アウトロー度)で、依頼の4タイプ(マナーにうるさい・守らない・正義感が強い・アウトロー)を表す。珍しい特徴は珍しくする(アウトローは約5%)。詳細は [05-crime-and-police.md](05-crime-and-police.md)。
- **「悪感情」は、マナー違反と犯罪(反社会的な面)と解釈した。** 怒り・恨みなどの感情そのものは、まだ入れていない。
- **マナーの行動はゴミ。** 食事でゴミが出る → 捨てる/ポイ捨て/拾う、でマナーが表れる。
- **犯罪は万引き・すり。** 欲求(空腹・お金)が満たされず追い詰められるほど起こしやすい。手を出す閾値は、正義感・マナー・アウトロー度・前科(反省)で変わる。
- **警察は巡査2人**(正義感の高い人を選ぶ)。交番、パトロール、目撃・通報・防犯カメラによる手配、追跡、逮捕、勾留(3時間・罰金 ¥300)。
- **ai_cpu に、行動の出来事の取り出し(`drainEvents`)を足した。** 世界への反映(ゴミ・盗み・逮捕)はゲーム側。ai_cpu は、犯罪・警察を知らない。

## 2026-11-22 (特性の割合・1日5分)

- **珍しい特徴は、珍しくする。** 睡眠の特性(夜型度・睡眠欲・昼寝好き)を、一様乱数 → 釣り鐘型で決める。極端な人(早起き・夜更かし・昼寝好きなど)は1割前後以下、ショートスリーパーは約4%。詳細は [03-sleep.md](03-sleep.md)。
- **特性は、人数分の分位点を並べて割り当てる**(`ai_cpu` の `stratifiedNormal`)。理由: 1人ずつ引くと、人数が少ないときに割合がぶれるため。
- **1日を 1200秒 → 300秒(等速で5分)にした。** 村人が歩く速さには、`WALK_SPEED_SCALE`(平方根で1200秒に対する倍率。300秒で2倍)をかける。

## 2026-11-22 (コンビニ・お金・ポーズ)

- **コンビニで食料品5種類を売り、村人は買って食べる。畑仕事の賃金でお金が増える。** 酒場(無料で食事)はなくした。詳細は [04-economy.md](04-economy.md)。
- **ai_cpu に「持ち物」(`resources`)と、行動の支払い・獲得(`costs` / `gains`)を足した。** お金も食料品も、ai_cpu から見ると持ち物の1項目。お金の意味はゲーム側。
- **1日を240秒 → 1200秒(等速で20分)にした(のち300秒)。** 理由: 村の移動に1日の2〜3時間分かかり、1日の行動が収まらなかった。行動の長さ・欲求の減る速さは「ゲーム内の時間」(時間・1日あたり)で書き、1日の長さは `game/src/time.ts` の `DAY_SEC` 1か所で変えられる。
- **ポーズは Space か P。** 世界の時間(村人・昼夜)と、プレイヤーの移動を止める。視点の操作と、村人の中身の確認はできる。時間の速さは ×1・×4・×16・×64(キー 1〜4)。
- **プレイヤーにも所持金(¥1,000)があり、コンビニで買う・畑で働くことができる。** 空腹などの欲求はまだない。

## 2026-11-22 (睡眠の個性)

- **睡眠の個性は3つの特性で表す**: 夜型度(早起き↔夜更かし)、睡眠欲(ショート↔ロングスリーパー)、昼寝好き。1人が複数を持てる。詳細は [03-sleep.md](03-sleep.md)。
- **個性の仕組みは ai_cpu に汎用で足し、睡眠のルールはゲーム側に置く。** 足したもの: `needDecayScale`・`durationScale`・`cooldownSec`・`inertia`・`AgentView` の拡張。理由: 睡眠のコードを ai_cpu に入れると、他のゲームで使えなくなるため。
- **寝る時間帯が終わる直前からは、新しく寝始めない。**
- 今後は「1つずつ整理する」方針で、テーマごとに `docs/0N-テーマ.md` を作る。

## 2026-11-22 (3D試作)

- **3D は Three.js + Vite + TypeScript。** 置き場所は `game/`。`ai_cpu` は `game/src/brain.ts`(この世界の定義)と `villagers.ts` からだけ使う。詳しくは [02-prototype.md](02-prototype.md)。
- **村人は `InstancedMesh`(体・頭・鼻の3つ)で描く。** 50人でも描画呼び出しは3回。
- **ai_cpu に「選ぶ」と「始める」の区別を足した**(`requiresEngagement` と `agent.engage()`)。理由: 場所へ歩く時間の間に行動が終わってしまい、村人が歩きっぱなしになったため。詳細は [ai_cpu/design.md](ai_cpu/design.md)。
- **欲求の減る速さは、1日(240秒)で収まるように遅くした**(満腹 0.0045/秒など)。

## 2026-11-22

- **新作として1から作る。** 別のゲーム(ふるさと百代記)とは無関係。`services.md` はそのゲームで使ったサービスの参考資料にすぎず、このゲームの構成を縛らない。
- **1人で遊ぶ。他のプレイヤーとの交流は今は考えない。** → 計算は全部ブラウザの中。計算用のサーバーは持たない。
- **GitHub には文書だけ送る。プログラムは送らない。** `.gitignore` で、`README.md` と `docs/` 以外を除外。送る前の確認は、毎回はしない(Claude への指示)。
- **村人の頭脳は `ai_cpu/` に分ける。** ゲーム・描画に依存せず、他のゲームでも使えるようにする。
- **`ai_cpu` は TypeScript・外部ライブラリなし・種つき乱数・状態は保存可能な形。** 理由: 再現できるテスト、セーブ、Node とブラウザの両対応のため。
- **行動の決め方は、まずユーティリティAI(点数方式)から始める。** 理由: 欲求・性格・状況を足し算で混ぜられ、調整しやすい。行き詰まったら他の方式との組み合わせを考える。
- **メインの枝の名前は `main`。**
- **プレイヤーの暴力は、パンチ1本にする。** 「喧嘩をしかける」コマンドは廃止。パンチが当たると、相手が殴り返す(喧嘩)か逃げる。理由: いつでも出せる直接的な操作のほうが1人称に合い、結果(反撃か逃走)は、相手の性格しだいで CPU らしくなる。
- **持ち物は10スロットで、選んだスロットを食べる・投げる。** 投げたものが人に当たらなければ、ポイ捨て扱い(罰金・説教の対象)。時間の速さのキーは `[` `]` へ移した。
- **会話は、「ほめる・けなす・立ち去る」の3択と、吹き出しだけ。** 記録(ログ)の画面は廃止。
- **見下ろし視点(地図)は、最初の3人称視点(自分を中心に回る斜めのカメラ)にする。** 別の2D地図は作らない(CPU の動きも、そのまま見える)。真上から見る案は、人の姿が分かりにくく、やめた。
- **住まいは、アパートが基本。自分の家は、お金がたまったら大工小屋で建てる。** 1人1軒・グレードアップは建て直し・建築は1日。区画は、プレイヤー用に、CPU が使わない分を残す。理由: 村の家が、全員の持ち家だと、お金の使い道・格差・建てる楽しみがないため。
- **家の見た目(3種類・色)と、広さは、データ(`housing-data.ts`)で決める。** 区画の障害物の半径・玄関・屋内の広さは、家を建てたときに更新する。
